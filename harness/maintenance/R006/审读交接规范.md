# R006 151—200章独立审读交接

授权：按照harness框架检查并修改151-200章。主笔 R006-main；审读者不得改正文或自签主笔结论。维护记录不推进400/D320、401/A31。

1. 先逐章完整读指定工作稿（第一遍不看作者解释、其他审读/决策）；在 `Bxx/initial-reader-notes.md` 记首次读者的地点、人物目标、因果、卡顿/退出/继续读位置。保留真实认识过程。
2. 再按AGENTS.md顺序读取项目总纲/阅读地图/分卷与第二卷卷纲/篇章卡/相应逐章卡、世界/角色固定资料、各台账相应历史截点及写作规范（正文与连载第九节、文风第二七节、黄金追读规范）。未读部分注明，不宣称全文事实审计。可检索台账定位后读完整对应条目，最新D320不能倒灌D100附近。
3. 只据硬规则/已发生事实作最小修复建议；基本设定存在两个合理解释则列 pending_author，不能猜补。涉及151以前或201以后只登记依赖。R005尚未发布的工作稿不得作为事实；读取R005待裁事项仅用于关联未决依赖。
4. 初审输出 `Bxx/initial.json` 和 `Bxx/initial.md`。JSON包含 reviewer（真实agent ID；若不知道请最终回复身份供主线程在独立元数据中登记，勿编造）、writer:R006-main、independent:true、body_first:true、manuscripts:[{chapter,path:工作路径,sha256}]、source_digest（标准json sort_keys=True ensure_ascii=False对manuscripts编码SHA256）、verdict:issues/pass、chapter_readings（每章实际地点/目标/选择/代价/两项推进/信息边界/钩子类型）、issues:[{id:R006-Bxx-001,chapter,quote:原文逐字,severity:severe/moderate/minor,category,problem,suggestion,status:open/pending_author,blocking:boolean,source_basis}]、standards（十类高频和五类AI模式按实际命中列原句/章号，未命中不虚构）、context_read（实际路径及范围）、checks（下面定义）。
5. `checks`每章五项：opening_pressure / protagonist_choice / visible_change / emotional_payoff / next_question；每十章再两项promise_payoff / progressive_stakes。每项 {criterion,chapter,quote:逐字正文,reason,verdict:pass/needs_revision,action:未通过必填}。不能仅词频自签质量。
6. 同时给 `Bxx/suggested-edits.json`：[{issue_ids:[...],chapter,before:精确且唯一文本,after:建议文本,reason}]。不得为了达到字数塞总结/验证动作；目标2200—3200纯汉字。无把握的不拟写，列待裁。
7. 主笔修改后会另行通知复核。复核必须读真实修后稿，对每条问题记录closed/open/pending_author及实际引句；输出final.json/final.md和reader-review.json（格式参考tools/check_reader_pull.py，schema_version:1,kind:review,profile:serial,writer/reviewer/independent/body_first,manuscripts/source_digest/checks,verdict）。事实与吸引力分开结论；有未解决阻塞不得pass。旧版本报告不可覆盖为新通过，追加v2。
