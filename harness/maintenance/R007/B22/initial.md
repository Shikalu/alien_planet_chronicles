严重问题：

- R007-B22-001 / 第211章 / “弥娅名下的暖手水照旧两勺，杜姨又给她的格子里挪了半块湿布——潮头里湿布比药金贵，捂在口鼻上，能滤掉汽里最烫的那一层。”：200撤暖手日耗，备用两勺未耗须承接；湿布不能筛去高热蒸汽。夜光应有来源且不暗示长达日夜持续自然强光。
- R007-B22-002 / 第211章 / “潮头第二夜，戌时末，车行北巷，卸讫，返。”：D77首日入夜；数纸不能先记第二夜，次章D78旬头不需更改。
- R007-B22-004 / 第212章 / “潮头第二天的正事只有一件：弄明白那一趟车。”：热汽危险仍派小石单人全凭湿布避险，需给实际撤路、视线停点；小石童年走沟两年可成立不必改；本章已旬头日，禁跟入巷后不能亲见卸载便门。
- R007-B22-005 / 第213章 / “旬头那天，潮头歇了半个凉时。”：213与212同D78，开头不再复演小石烫伤后跟车；尚未受赠水不能说吃人家水。票手印未对本人不能写对上。
- R007-B22-007 / 第214章 / “翻出两处念漏的：一样是“转”字底下的角注，一样是批号。”：五转两绝需列满五转；一直左手写不应又换左；分持站柜副本不应无交接回棚同时贴。
- R007-B22-009 / 第215章 / “中间凭空抬了一道。抬那一道，得有一股外头的劲顶着——泵，或者更高的水头。”：水管中抬高并不单独证明外泵/更高水头，必须先说未加压可运行所需压差；只核本泵停不排其他泵，不能定论；读数无声不能判非本台。
- R007-B22-011 / 第216章 / “潮头里数坡口的汽数了一冬”：本夜只有一夜现场守，不能说两夜间隙相同；四人含丁字三，却天亮撤四人后丁自回棚无交岗；年两回不能称旬检。
- R007-B22-013 / 第217章 / “细支的管是空的。白日里管子里没水，引管接上去，接出来的是一截空管。接的人大约也明白了这个理，拆了就走——可划痕留下了，木屑留下了，管箍上一圈勒出来的印子也留下了。”：引管既拆走，不能在无实物下识出变径短节、判已接空管及操作者心理；须依箍旁留下短节实物（保持台账已有短节）并保待核。
- R007-B22-014 / 第217章 / “那管子里的水，八成就是北巷的水。咱们接自己的恩人的管，算什么？”：D81为D78旬头后第4日，所谓旬里十四天不可能；馈水要到219才发生，不称恩人；判断水路有未闭合环不能八成直接视实。
- R007-B22-015 / 第218章 / “她把重编册翻到批注页，跟站册抄本上那三个批号并排一放”：不能拿林栖手抄字判签者原笔。可比较同一重编原册已有批注页原批号、重编签与领讫签，守住原已发生同手结论并保‘人是谁未知’。
- R007-B22-016 / 第218章 / “三笔水，同一个门牌底下，没一滴落到住户的缸里。”：旧号后窗水存在去向待核，不能断无一滴入住户缸；D82天擦黑不能有今夜三更记录；当晚潮头仍尾不称过后。D88距D82六日正确。
- R007-B22-017 / 第219章 / “水是潮头里备下的，人是潮头过了才来的。”：干湿痕不能定备水时间或送者；三样封蜡只证封装相似不能‘来路现核’；清与静置不等于可直接饮，不能让缺水先喝后判。只收可见交接水质、保未知。
- R007-B22-019 / 第220章 / “两日之后是旬头，旬头还有五天。”：D83距D88五日，两件只够两日不能称两日后旬头；角行六天需改五天。
