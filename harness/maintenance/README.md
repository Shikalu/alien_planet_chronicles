## 如何读这些资料

- **当前进度**只查 `status.json`；本目录不再维护第二份动态状态。
- **返修是否验收**先查各批 `record.json`，再沿其中的签名读取实际初审、复核、发布绑定、回填与审计。文件名带 `final`、`approved` 或某次脚本退出0，不单独构成整批通过。
- **历史截点**原样保留。旧报告的“当前、未完成、待裁”描述当时；后来裁定及验收以该批最终记录关联的证据为准，不删除失败轮次或倒签旧报告。
- **文档整理**不重新认定文学质量、不改正文或事实资料，也不推进连载状态。
