# 第八卷收官状态快照｜第800章／D947

故事止于D947末凉的栈城高台。两趟条件民船已经抵岸，通行从同陆交口沿山道转到四层备料坪，步行过桥至五层。林渡和弥娅在低门台阶等抱字板的孩子，桥头喊出“邻船”。《异星录》第一版于五层档案馆开放留阅，包含双方旧说、亲见落款、可追溯实证与可续注的异议。

| 项目 | D947最后证实 |
|---|---|
| 林渡 | 签任公共工程总监，管排程、料工和公开回问；现场各原岗掌启停。右臂吊、左掌麻仍在。以自身原民水份给第二航来客。 |
| 弥娅、林栖 | 弥娅左腿伤、原测潮仪仍不读，五层校档和教学。林栖维护五层公用小冷凝站，原民水与站水分算，按当班合格量排；换芯仍有欠费。 |
| 阿九 | 右踝禁负重，旧车轨刹和传力大匣仍封停。手控短驳由两船主负责，坐位、撤退和独立停杆限定同陆，电格两用归零，泊同陆卸具位。 |
| 工程 | D880三、六层单元保管与限档使用实际续到D960末凉，三层实架与六层独立检修回路协同。D899和D940各一格实耗，作应急一格封存。D947齐D940四处实回，两岸各自闭锁；原民水不入工程回路。 |
| 航运、桥和住房 | 第一航D912离东岸、D914到交口，第二航D943离、D945到。定向民航条件不代替海峡环流当班审批；旧首船仍扣泊，低脚仍禁靠。新桥错时走水车、照护和行人，欠顶木两根已补一根。 |
| 死伤与档案 | 林岑D606确认死亡、D613实葬。点火、续封守密、后期救撤分列，家人不继罚；原签寄期已满、无新凭据，受护簿保持分持。第066章坠失伤员及第095章来岸放绳人分开待查，旧称和末见范围遵本批核实的权限，住处另封。 |
