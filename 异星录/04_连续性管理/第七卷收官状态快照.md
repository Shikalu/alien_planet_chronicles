# 第七卷收官状态快照｜第700章／D611

本快照对应第700章结束时现场可确认的状态。以A51—A60实际正文、收件原记和各批连续性报告为依据。第701章由靠山高位接起。

| 项目 | 现状与接续 |
| --- | --- |
| 林渡、弥娅 | 两人均在五层贴石山门后的高石。林渡右臂吊带及左掌旧麻持续，收原车最后一趟实停回条、另记坠城后车况待问；行板交在场守门者记未安置者，自己去看坡口。长裂尺无完整齿仍贴身，退栓走位副页系祝衡抄、看槽原工验签所得；退栓实位原图入四层旧修台由祝衡经手。弥娅和实际换岗者撤至石隔后，已把湿图抽出，让目击者分别补所见边界；旧测潮仪未恢复，局部岸测不代表完整海况。 |
| 林岑、林栖、槐七 | D606末凉两名最后实查待撤者先后过桥，海座红线全露停放。林岑先退门坎内墙肩，木肩失脚、窗板堵门，只按两岗回掌独自抢退；双脚已过黄布，遭靠山近岩另一跨旧檐梁压倒。遗体实取，两照护者分验，确认死亡。林栖见遗体后持其私人扳手回塔，扳手未借作闸具；D611率原泵班合柄退上高石，仍分守原出水／回接账。槐七在四层山端主持停桥、收工、验梁与救护；没有坠城后的实到回件。遗体先入四层高石间由守间成人实接，灾后高石间与后续安葬未核。 |
| 阿九、迟棠、原车 | D598阿九右踝遭限位托重创，关节承面永久损失、禁止负重，退出一线驾驶；左膝旧伤加痛另记。末次实信D608在三层靠山救护棚，坠城后的棚址、人员和伤情均待。迟棠在D609实际驾人工短轨原车停干卸点，两卧托与一随护同趟实到。原右刹、两短挡、独立锚用于停车，车未跨海。岸台长缆根扣旧石环，第一石口第二停绳接尾后长缆回原处；D609长缆及两短挡续借到实停，分别待原主核收，无再发准条。大匣隔离，备用牵引架缺件；车况不据坠城前的回签推断。 |
| 人员与去路 | 四层中转桥海向活动接板、外连缆与湿架去水，靠山两主梁木脚从五层仍可辨在岩槽；四层桥不可按原划走向海端。新卸载棚为背山步行接转点，干卸点为三层短轨卸点，两处实到分录。D611贴石路线先送两位能自行上行者，另四名慢行住户经低口到石内；工班与扶行者另记。寻子的母亲收到其儿子由报路人亲见已在石内第二接点的签。半城坠落后哪些地方还有人、能住多少、可放哪条路、受灾人数均待核，旧066／095仍分别失联。 |
| 水与冷却边界 | 六层签准局部工程试仓36壶。638出12，回接7，差5；650出12，回接10，差2；698出6，回接5，差1；700出6，回接4，差2；D611专仓0。回接数字是各次历史实收，回接水禁饮禁复泵，差额为沿程滞失或未能接到。海支保持闸锁，铜肩末次降一格只及见证带内的承托和退出时段。生活配给仍沿五层83.5申请／60实到／23.5缺／回补0口径，病幼20壶独立；三层救护棚上一条可核当班医水4壶用1余3，不能推成全城。上城整座水库余量、核心、水路新状态待实查。 |
| 档案与旧政治状态 | 林岑D605签本地爆破、续封及离家另问的三份原证词，D606签抄由短轨去干卸点独存；原件由经手成人步行另线，D611实收回条到高石。林岑点火与续封责任未随守桥死亡撤销。当地爆破按当前年序约十七年前，距开篇十六年前；与早约一百七十年的跨区域封锁、本次热海坍塌分别立项。早期受护名册原簿的独立保管沿原有交接，原证词与原簿分物。第五卷正式撤护、扣舟、东支闭锁等依末次实信延续。 |
| 下一章入口 | 海侧半城永久失去，靠山能辨之屋脚及高石暂留；先核未安置者、可放人去的具体住位、停泵后承托和可通石路，继续等三层医护及车辆实报。跨大陆共同工程尚需分段勘测、授权与施工。 |
