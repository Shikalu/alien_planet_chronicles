# 角色圣经

## 主角组

### 林渡

| 项目 | 设定 |
|---|---|
| 年龄 | 19岁；男性；下城区互助会登记的“第七码头水工”、木架攀爬者 |
| 外在目标 | 先完成一环送水、找到失踪父亲林岑，救出妹妹林栖 |
| 内在缺陷 | 先保身再说；不信宏大理想，害怕成为像父亲一样的抛弃者 |
| 能力 | 识别木材受热受潮后的结构变化；熟悉一环至三环路径；现场判断快 |
| 弱点 | 不会读旧文字；公开表达弱；遇到父亲问题容易冲动 |
| 核心物件 | 三齿木尺，测承重，后藏潮汐档案密钥；个人水票夹用于配送核验 |
| 声音 | 句子短，先报位置和风险；紧张时数梁、数脚步；对陌生人先报路线和票规 |
| 结局 | 栈城公共工程总监、《异星录》第一作者 |

成长阶段：求生者（1—50）→领路人（51—100）→质问者（101—200）→破局者（201—300）→联络者（301—400）→承担者（401—500）→指挥者（501—700）→记录者（701—800）。

### 弥娅

| 项目 | 设定 |
|---|---|
| 年龄 | 21岁；澜陆潮庭测潮员、失踪勘探队成员 |
| 外在目标 | 找到导师与勘探队，带回冷却技术 |
| 内在缺陷 | 相信澜陆官方史，先入为主把衡陆人视为掠夺者 |
| 能力 | 读取潮汐、星象、热流；使用测潮仪；会澜陆旧档案格式 |
| 弱点 | 衡陆语生疏；不了解栈城阶层规则；容易替族群保密 |
| 核心物件 | 银灰测潮仪，藏有缺失录音和两陆旧地图 |
| 声音 | 先说数据、后说情绪；衡陆语准确但不自然，熟悉后开始使用栈城俗语 |
| 结局 | 跨大陆学校与档案馆主持人 |

成长阶段：失乡者→证人→译者→拒绝独占者→民间使者→停机行动者→守门人→建设者。

政治身份单列：251—350拒交旧仪器中的存档载体，承受合作条件收紧与失信；351—499建立民间使者作用，不等于获得官方授权。第500章因公开本方删史、拒绝资料独占，首次被潮庭正式宣布为叛徒，官方保护破裂；此前威胁、污名不得写成已生效判决。此为2026-09-30作者确认的C01，详见[后七卷设定决策与执行约束](../00_项目总览/后七卷设定决策与执行约束.md)；未来政治事件须写成正文后才回填当前状态。

## 重要配角

### 林岑

46岁，林渡父亲，前断阶维修师、无面者首领之一。参与距开篇16年前的栈城本地“坠城日”爆破，当时约30岁；负责第三组孔位并点火，后来发现被议会利用，仍须承担本人隐瞒与续封守密责任。约170年前的跨区域封锁是更早历史，不是他的亲历。爆破、后续守密与离家失踪分开记，不以16年前自动填离家日期，也不改变林渡、林栖的亲缘。不能被洗白。第七卷守桥牺牲，留下证词和木尺刻痕。

### 阿九

32岁，房车修理师和黑市零件商。嘴贫、怕麻烦、爱占便宜，对机械有责任感。房车底盘藏列车船启动核心。房车被抢后仍选择救少年团，终局驾驶改装列车船，右腿留下永久伤。

### 祝衡

29岁，上城区巡查官。相信秩序高于真相，后发现议会把巡查官当弃子。熟悉权限系统和政治谈判。转向公开档案，成为联合委员会司法记录员。距开篇16年前约13岁；他的封锁执行责任属于后来任职期间的可证行为，不能倒写成当年爆破的成年巡查官。

### 林栖

13岁，林渡妹妹，热能电池学徒。前期被保护，中期掌握配给算法，后期主持公共冷凝站。她代表普通人技术权，不能只作为人质。

### 槐七

年龄不详，前木匠，无面者战斗导师。相信暴力守密是最低代价，后因伤及活人而改变，率先摘下面具。

### 赫连

议长，主要制度反派。曾让上城区连续十年保持最低死亡率，因此相信精英集中资源才是理性。计划牺牲栈城换武器站和避难船，不是单纯疯子。

### 白礁

弥娅导师，澜陆测潮学者。曾被潮庭收买，删改过资料；后留下赎罪记录，与弥娅共同公布两陆隐瞒史。

### 鸦母

黑潮教团祭司，以“热海神罚”煽动异星仇恨。教团高层暗中抢夺撤离名额，最终因内部矛盾瓦解。

### 房车少年团

三名下城区少年：岑野（领头，胆大）、麦穗（修理快）、小石（记路强）。抢车不是纯恶作剧，而是为了救被困弟弟；后来成为信使小队。

## 人物底线

- 林渡不会为了追父亲主动放弃妹妹或整片街区；他可以做痛苦排序，但必须公开代价。
- 弥娅不会把澜陆错误归咎于所有衡陆平民；她会反复修正自己的阵营偏见。
- 祝衡不会在没有证据时公开指控，也不会为了保职位再次参与灭口。
- 阿九会嘴上逃避，但关键时刻优先救人；他的喜剧不能消解死亡。
- 赫连可以被理解，但不能被洗成正确；他的方案必须真实伤害普通人。
