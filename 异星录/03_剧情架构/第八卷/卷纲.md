# 第八卷《异星录》卷纲

> 全部为未发生规划；跨卷起点、因果链和时间尺度见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 半城废墟、跨区安置与双陆互疑；林岑已死、阿九右腿残伤、旧能源与储水不足，司法和公共工程必须同时开展。 |
| 必须解决 | 制定非血统、非旧权限的居住与配给办法；依法追究各方责任；取得海峡闸门、双陆测潮数据、栈城冷却核心三项资源；施工、试运行、迁城与教育并行。 |
| 中点反转（750） | 三项资源已谈妥却不能照搬旧联盟集中控制：自然热周期更强，旧图也遗漏牺牲区与维护人力。公开失败试验并扩大迁城，比承诺复原原城更必要。前置：725基线变化、742停机后的持续热量测量。 |
| 后半卷行动 | 经分段试验修订环流图、闸门联动和报警；教团清洗派最后袭击被信徒拒绝配合与实际保卫共同瓦解，不把所有信徒赶出配给。联委会接受可撤换的工程授权，迁居者能追问损失。 |
| 卷末不可逆变化 | 完成共同潮汐环流工程并转入长期维护，海峡开放但余温仍在；新桥落成、公共冷凝站开放、跨大陆学校与档案馆开办。城市不回到原样，双方能合法拒绝秘密献祭。 |
| 人物 | 林渡任公共工程总监但不垄断档案解释，完成《异星录》并保留不利于己方的章节；弥娅主持学校和档案馆；祝衡任司法记录员；林栖主持公共冷凝站；阿九以辅助装具驾驶改装列车船。 |
| 资源 | 闸门要两边值守与维修，数据要共享校准与版本保存，底盘核心需与上城区残存水库系统协同；无法凭一件核心或一段频率开海。学校与档案馆占用真实人员、纸张、房屋和供水。 |
| 伏笔 | F07于742完成自然周期与工程叠加解释；F04/F08/F12于744从旧制度、共同史与民间接受机制上回收；Q4落到无面者保护与伤害的双重档案。失联者保留公开查找程序，不能为了闭合全书强行“全员找回”。 |
| 读者知情 | L6：完整工程因果、各方责任与制度防复发；结尾可追问维护和新生活，不再扣留主线谜底。最后“邻船”来自持续航行与互学，不是一次口号。 |
