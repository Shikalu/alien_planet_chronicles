# 第三卷《上城区无门》卷纲

> 以下卷级表保留开写前规划；本卷正文已完成，实际发生以[逐章卡实录](逐章卡.md)、动态台账及文末收官说明为准。跨卷原规划见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 封存者和孩子在五层外缘受助区，四层通道脆弱；公布名单引发连带配给停用。主队无有效身份，且不能把孩子作为游击队随身带走。 |
| 必须解决 | 让实际居民而非权限等级获得基础水；找到普通上城居民去向；揭露家属先走、劳作者被留的具体机制；证明白船航线和权力/物资转移的关系。 |
| 中点反转（250） | 停用自动剔除让活人重新进入供水队列，却立即显露真实需求超出当前可用产水。删除者不只是藏人，还在隐藏系统亏空。林渡必须保水库、公开减额，不能宣布“开门等于解决一切”。前置：218空置住址仍领水，237产水与发放差额。 |
| 后半卷行动 | 林栖与原值班工核验配给规则并人工接管局部支路；林渡救援被迫下迁的上城居民。弥娅为保存另一份译档离队，未提前抵达澜陆；分离源于方法冲突与未告知路线，不用恋爱误会。 |
| 卷末不可逆变化 | 公开账替代部分身份配给，水库没有被炸毁但缓冲储量消耗；284查明精英家属已转移，300把第一卷已知目的地与实运清单、军用通道及家属名单对上。官方停运，山腹货运成为必要选择。 |
| 人物 | 林渡学会限制胜利的范围，放弃报复性毁库；林栖从抄账进入受监督的技术岗位；祝衡查家属的努力不自动换来团圆；赫连先修真实水库故障，再要求牺牲外缘，治理成绩与排除成本同时可见。弥娅本卷仅承受拒交载体后的合作条件收紧与失信；正式叛徒判决固定在500。 |
| 资源 | 固定水库/冷却塔的运行权不等于所有权；新增水有日常耗用与检修停产。档案潜入耗费换班与抄录人员。外借表和芯格记还借，旧测潮仪不修复。房车继续停四层。 |
| 伏笔 | F04在210/284推进，744才完成制度性回收；F09在300完成撤离实运与利益证据链，不重揭名称；F11在206/275补实物流转证据，560追到资助责任。 |
| 读者知情 | 仍为L3。可以看到旧资源争夺档案的栈城一侧，不凭此推出潮汐联盟或两边共同删史；已知澜陆存在，悬念改为“谁能正式回应、是否愿意合作”。 |


## 实际收官：第300章／D164

- 已发生跨度为201／D68—300／D164，共覆盖97个日序；不回拨既有时间以迁就卷间预估。
