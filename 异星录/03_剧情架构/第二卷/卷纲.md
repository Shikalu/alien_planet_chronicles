# 第二卷《黑暗断阶》卷纲

> 本卷正文已发布；下表保留卷级原规划，已发生情况以逐章卡实录、对应时点台账和收官状态为准；跨卷起点、因果链和时间尺度见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 承接上述T8平台状态；101章不能跳过孩子。不是“再次第一次穿越断阶”，而是被上城排除后，经新探明的检修路线回到四层深段，救出被封存者。 |
| 必须解决 | 给孩子与伤员建立连续供水、照护、登记；找到不依赖身份印记的局部路线；核对林岑证词和本地爆破执行链；使无面者接受受保护的公开作证。 |
| 前半卷行动 | 先退入七层检修遮蔽处，向六层外围、五层外缘分批转运；用维修劳务换限量供水。上城拒绝收容后，与槐七探新线路降至四层侧廊，发现封存工程师和灾民。 |
| 中点反转（150） | 两份互相独立的配给/用工记录证明：系统把这批人列死后，仍把他们的维修劳动记入产出。封存不仅为灭口，也为维持少数人的供水。林岑曾参与续封知情范围成为新追问。前置：124耗材领用，143活人的工具工号。 |
| 后半卷行动 | 无面者分裂；166核实持续敲击的工程师身份；五层外缘冷却塔只获得短期人工控制。林渡反对用断水复仇，188公开本地爆破多方执行责任链；200只打开四层居住段与短联络通道，深轨和三层主入口仍封。 |
| 卷末不可逆变化 | 封存人群被移出，名单和证词多点留存，无法重新秘密抹除；议会撤销相关街区配给，追捕扩成整片区域封锁。人救出来了，但临时水点无法支撑扩大的受助人口。 |
| 人物 | 林渡从领路变成质问和组织作证者；弥娅先保档案的偏向被实际救援纠正，仍保有查档权；林栖负责实领与系统账对照，不会万能破解；祝衡作为被系统列死的证人承担本人任职期封锁责任，不倒签为16年前爆破执行官；林岑活着接受质询；槐七已摘面，本卷推进名册保护，不重复“首次摘面”。 |
| 资源 | 首批处理水来自实际检修储水柜，之后以维修换连续限量供水，均须取水验源、清点、分饮用/医疗/设备用途。新电力来自固定检修供电与外借芯格，不能充活旧仪器。原仪器只作档案载体；局部热况靠现场观察和借用固定表。房车不移动。 |
| 伏笔 | F03在188回收距开篇16年前本地爆破责任，先核日期与物证；F06在166局部答复，390再解释更大网络；F10在119触碰；F13只确认本地通信条件。F14及095失联者继续分列。 |
| 读者知情 | L3：知道活人如何被制度删除、地方封锁由哪些岗位执行；不知道两陆共同史、同日空白的双边责任、海峡武器作用。赫连本卷只核对可证的岗位/批示，不认定他是跨时代全部阴谋的总签发者。 |
