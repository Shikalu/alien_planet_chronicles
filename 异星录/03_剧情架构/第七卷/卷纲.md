# 第七卷《木城倾覆》卷纲

> 全部为未发生规划；跨卷起点、因果链和时间尺度见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 巨浪将至、回流旁支受损，停机责任遭各方争夺；列车船和临时安置点负荷已满，不能重置成一城健康居民。 |
| 必须解决 | 测定剩余承重与撤离顺序；疏散上下城及断阶居民；校准喷口和局部冷却；把不能救的范围公开，保住证词与实际人口。 |
| 中点反转（650） | 满负荷冷却试验只够稳定半城承托，若追求全保将耗尽列车船与水库余量，使人员撤离失败。选择拆除不保区材料供桥与运人。前置：620岸侧回流、638梁载/泵量试验。 |
| 后半卷行动 | 祝衡在撤离现场公开档案与责任；林渡下放分区指挥，弥娅与轮换队校准海底喷口。林岑保留全责证词后守桥，694牺牲且死亡确认；不是神秘失联。 |
| 卷末不可逆变化 | 700半座栈城坠入热海，旧冷却只守住余下承托与撤离时间；林岑不能复活，阿九右腿永久伤，与原左膝旧伤分列。城市住处、产权和工作岗位永久改变。 |
| 人物 | 林渡不因父亲死亡宣告原谅爆破；林岑证词由多人接续。林栖主持冷凝调度但仍需工班，槐七组织撤人并承担守密损害；弥娅接受轮换与救助，拒绝孤独英雄证明忠诚。 |
| 资源 | 拆城梁材不可复原，桥缆报损，医疗占用处理水，列车船车体改造失去原居住功能；部分上城储水耗在延缓坍塌，八卷须长期补水和迁居。 |
| 伏笔 | F01在694把裂尺刻痕变成可核验施工/证词交接，不变神器；F07在620推进，Q10于700回答“不能完整保城”。066、095无新证据仍保留未确认，不借全城坠落擅自追认死亡。 |
| 读者知情 | L5完成：旧系统只能延缓，撤离胜利不等于城市获救；共同工程仍要长期谈判、勘测和施工，不在700突然宣布已建成。 |
