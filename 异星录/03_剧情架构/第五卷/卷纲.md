# 第五卷《澜陆来客》卷纲

> 本卷固定规划见下表，逐批已发生状态见[逐章卡实录](逐章卡.md)。第401章实际起点继承[第四卷D320收官快照](../../04_连续性管理/第四卷收官状态快照.md)。跨卷因果与时间尺度见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 航线有限开放、澜陆使团到来，双方民众都有真实损失；衡陆不是栈城一个议会的同义词。孩子与伤员仍由安置组织照护，不全员跨海。 |
| 必须解决 | 建立能实际履行的饮水与通行交换；让双方记录可互证而非互相指控；追问白礁删档责任；避免用弥娅和核心换单方垄断。 |
| 中点反转（450） | 双方单独保管的数据都无法校准同一条航段，且缺页并非仅发生在对方。问题由“拿到先进一方的答案”转成“谁愿交出不利于自己的原件”。前置：423航图偏差，441双方抄本版本不一致。 |
| 后半卷行动 | 白礁先提供可核验删改样本，476与弥娅及衡陆档案共同完成责任核对；公开本方证据而不拿受害者当筹码。潮庭强硬派以资源外泄夺权，拒绝开放原件者退出协定。 |
| 卷末不可逆变化 | 两陆伪史的双边责任公开，无法恢复各自纯洁无辜叙事；民间合作站成形，官方保护破裂。弥娅在500首次被潮庭正式宣布为叛徒；发布者、载体、接收者和现场撤护须写实，其他港口后续按送达情况执行，不全陆同时生效。 |
| 人物 | 林渡公开本方侵害，不代所有衡陆人认罪；弥娅不再替潮庭藏档，两人以公开站队确认关系；白礁认罪不免除资格限制与受害者质询；普通信徒、港民和商团有不同选择。 |
| 资源 | 海运粮药与栈城维修劳务/处理水交换，协议需交货与违约记录；测潮数据分保管、复制和使用三种权利。共享设备为有来历的新设备，不能说旧测潮仪重新精读。 |
| 伏笔 | F02/F10/F13在476交叉回收，F08/F12确定双方删史与共同工程史的基本事实，744再追问民间为何接受和如何防复发。F11继续保留幕后物资链。 |
| 读者知情 | L4完整：两边上层都删改历史，双方都有受害者；不把数据异常直接解释成武器加热因果，该结论留501以后实验。 |



## 第400章已发生的启动约束

来客尚未抵达，仅有自报澜陆沿潮港外侧值守台两轮新问答及会面转达意向。原车留同陆近岸台待查导轮新沟，阿九左膝痛、大匣耗后；孩子姨母在岸侧原号照护，不全队跨海。六包0兑，D324借具/照明/盘管、D327檐、D328旧4、D332新2各自未到期；作业灯需补能，借片返棚/广播副纸上送回条未收。401先核轮套、水食与会面条件，船到/授权/物资实交须写成现场过程；不将海峡航线或官方保护当作已生效事实。
