# 第六卷《双陆战争》卷纲

> 全部为未发生规划；跨卷起点、因果链和时间尺度见[剧情架构索引](../README.md)。

## 卷级执行边界

| 固定项 | 卷级执行边界 |
|---|---|
| 开局状态 | 民间互证触动资源特权，澜陆舰队封锁，衡陆相关军政势力准备启用海峡武器；栈城议会不等于衡陆全部政治力量。 |
| 必须解决 | 保住粮药走廊；取得可重复的武器—热流因果证据；三路协作阻止持续释放；不把停机等同于热量消失。 |
| 中点反转（550） | 有限停火与小幅降载试验显示近岸暂凉而另一支流更热，冷却宣传实为热量转移。封锁切断校准人员后，停机也可能产生回流。前置：520同步温差记录、530接口与阀位对照。 |
| 后半卷行动 | 谈判路换检修窗口，维修路修回流旁支，武器站路切断强制启动；560揭开教团制式武器供货责任。双方强硬派拒绝全面停战，弥娅关闭危险装置，团队选择不向澜陆居住岸转移热流。 |
| 卷末不可逆变化 | 持续攻击被阻止但全面停战失败；先前储积热量与未完成疏导的回流形成巨浪趋向栈城。主队知道风险仍选择避免更大伤亡，必须承担撤城后果，不能归为无因天灾。 |
| 人物 | 林渡转为分工指挥，不能三个战场瞬移；祝衡负责见证停机条件；阿九和林栖在维修路轮值；弥娅关闭武器依靠团队校准，不靠孤身献祭。 |
| 资源 | 三路行动分别占用运输、药水和电池，预留撤回载荷；列车船不跨越未修复深海航段，跨陆人员靠有限海船接驳。回流旁支损毁、修复材料不足延续到七卷。 |
| 伏笔 | F11在560回收供货责任；F07由黑汽环境推进到热流后果；F08在530成为实验接口证据。Q1只得人类工程部分答案，自然周期与完整方案留八卷。 |
| 读者知情 | L5：武器会加速局地升温与扰乱环流，旧冷却只能缓解；知道需要双边闸门、数据、核心协作，但还没有已验证的终局施工方案。 |
