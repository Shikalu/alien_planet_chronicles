# 黄金开篇与持续追读规范

本规范补充AGENTS与原连载规则：从读者为什么愿意读、为什么继续读、期待何时兑现来审稿。使用同一套原则检查短篇和长篇；本项目按既定灾难、人物温度和有限工程胜利来兑现，不改八卷路线、不提前揭谜、不用无代价打脸代替人物成长。

## 黄金开篇：检查读者实际打开的第一页

有楔子就从楔子审起，不得跳过前置说明后才声称“第1章开头抓人”。记录真实入口前100纯汉字和前3—5句的原文：有没有具体的人、异常/冲突或正在逼近的后果；读者愿意追问什么，而非只学会几个术语。100字是定位问题的观察窗，不是保证商业结果的分数。

第一章应让读者知道：跟谁走、他此刻要什么、为什么现在必须做、什么拦着他、失手会失去什么，并通过主动选择显示人物。背景只解释当前行动用得上的部分；天气、地理、制度和物性可以出现，但须改变人物选择，不能让危险停下来等解释。

前三章共同建立本书承诺：废土压迫、有限能力救人、付出真实代价、追索被遮蔽的事实。要有一次看得见的局部兑现，使读者相信人物行动有效；同时打开由本次选择造成的新压力。第三章不必解决大谜底，也不能连三章只许诺“后面会好看”。

开篇专项必审项ID：`first_page_hook`（真实第一页的抓手）、`protagonist_stakes`（人物目标/阻碍/代价）、`three_chapter_promise`（前三章承诺与初次兑现）、`exposition_cost`（说明是否打断行动/重复已知）。每项给章号、原句、读者实际感受、判断和修改方向。

## 每章：让读者获得变化，而不只是在账上推进

每章独立检查五项：

| ID | 必须回答的问题 |
|---|---|
| `opening_pressure` | 前3—5句把本章要处理的压力/异常/目标放出来了吗？上章的危机是否被拖到背景后？ |
| `protagonist_choice` | 主角或视角人物作了什么选择？若换成任意搬运工，这章还完全一样吗？ |
| `visible_change` | 章前章后什么变了：行动结果、认识、关系、资源或规则？用了新地方名称却重复同一工序，不算新的变化。 |
| `emotional_payoff` | 读者得到了什么回报：救人成了、失败可理解、能力被验证、信任改变、局部真相落定或代价击中人？不能只写“情绪到位”。 |
| `next_question` | 读完后能具体说出为什么想点下一章吗？钩子是否由人物选择和世界压力自然产生？ |

必要的承压章可以暂缓兑现，但要写清延后的期待、到哪一篇兑现以及当前获得的新信息/选择。不能无限欠账，也不规定每章必须打脸或翻转。仍按原3/5/10/25/50/100章节奏安排升级与回收。

## 每十章：承诺、兑现和升级

写前篇章卡补“读者期待→本批局部兑现→实际代价→下一批新期待”，以及人物/关系应发生的可见变化。写后检查 `promise_payoff`：原来让读者等的事，究竟在哪一章通过什么场景兑现，哪些未兑现、为什么、何时再交。

再检查 `progressive_stakes`：新篇是否改变选择难度、受影响的人、资源条件、关系或真相层级。连续修管、核账、借工具可以符合世界设定，但每次必须承担不同的戏剧作用；相同目标、相同障碍、相同对话和同类结论反复出现，应压缩重复表达或重新组织场景，不能凭空加事故制造变化。

对已发布正文做结构调整时仍遵守事实优先级。若需要改变已发生事件、既定揭示节点或重要代价，记录方案及影响，按根规则处理；不能以“追爆款”为由静默改设定。

## 审读证据与放行

独立读者先只读实际稿件，再看章卡和台账。报告分两条结论：事实/逻辑是否可理解；吸引力/期待兑现是否达标。前者通过不能替代后者。

吸引力审读JSON统一放 `harness/reader-reviews/批次ID.json`，记录实际稿件路径/SHA/摘要、真实审读者、主笔、先正文后资料顺序、逐章五项及篇章两项证据。开篇涉及楔子和前3章时还须开篇四项。每项至少有一段实际原句、理由和结论；未通过须有具体修改方向。

`tools/check_reader_pull.py`只核版本、覆盖、原句是否在稿件及未通过项，不以关键词/字数自动判断好不好看。`gate`要求新批次独立吸引力审读通过；稿件再改则证据失效。作者自查可保存为`diagnostic`，始终不等于独立验收通过。历史已发布批次不补造报告，覆盖率如实保留未审范围。
