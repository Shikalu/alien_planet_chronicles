# 正文与连载规范

## 1. 视角

- 默认第三人称限知，林渡为主要视角。
- 单卷非林渡视角不超过20%。切换必须带来主角无法获取的信息。
- 同一场战斗不反复切视角；先固定空间关系，再写动作。
- 反派视角只展示正在作出的选择和代价，不直接解释全部阴谋。

## 2. 单章结构

```text
开头10%：异常、危险或新信息
中段70%：行动、阻碍、主动选择、局部结果
结尾20%：反转、倒计时、身份线索或关系钩子
```

每章必须具备：

- 一个局部目标；
- 一个具体阻碍；
- 一次主动选择；
- 一项真实代价；
- 至少两项推进：目标、线索、关系、资源、规则；
- 一个不重复前两章类型的章末钩子。

## 3. 场景写法

- 每场至少使用两种感官：热度、湿度、声音、木材触感、盐味、蒸汽遮挡等。
- 环境不是背景板：木材开裂会改变路线，潮汐会改变时间，水票会改变关系。
- 解释技术时先让角色使用或失败，再补必要原理；避免百科式连续说明。
- 动作场景中明确谁在什么高度、距离、方向，避免“冲过去、打倒、跳开”的空间空转。

## 4. 对白与人物声音

- 林渡：短句、先报风险，情绪高涨时更少说话。
- 弥娅：先数据后情绪，衡陆语生疏；熟悉后学会使用下城区俗语。
- 阿九：用玩笑缓冲压力，但在真正死亡场景中必须收住。
- 祝衡：制度化、克制，失去权限后句子逐渐口语化。
- 赫连：擅长把牺牲包装成统计和效率，不能靠辱骂推进。
- 童年或方言表达不以口音作为笑点，语言差异必须服务于误解和理解。

## 5. 钩子与悬念

钩子类型轮换：危险、发现、身份、选择、时间、关系、世界。连续两章不使用同一类型，危险钩连续不超过三章。

大反转前至少埋两处可回看线索。反转必须改变角色选择或路线，不能只改变读者知道的背景。

## 6. 感情线

- 以共同选择、信息交换和风险共担推进。
- 表白不早于关系和阵营真正稳定的阶段；前期用称呼、保护和分工表现亲近。
- 不设置无功能三角恋，不用失忆重置关系，不用血统解释吸引力。
- 感情冲突若不改变任务、资源、阵营或信任，应删减。

## 7. 伤亡、失败与升级

- 重要角色死亡不可复活；死亡后至少三次出现岗位、遗物、争论或资源后果。
- 主角不能连续三次依靠个人聪明解决危机；至少一次依靠配角、制度或失败后的补救。
- 每次重大胜利至少付出时间、设备、信任、人员、舆论中的一项代价。
- 能力成长必须可观察：判断范围扩大、组织人数增加、谈判对象变化、工程规模升级；不凭空获得超能力。

## 8. 审校清单

```text
[ ] 人物行为符合当前目标、信息和伤势
[ ] 地点移动符合地图与时间窗口
[ ] 水、能源、装备和人员数量已更新
[ ] 新技术写明限制和失败方式
[ ] 本章没有静默改写硬设定
[ ] 旧伏笔没有被遗忘或无解释改变
[ ] 结尾钩子提出具体问题而非空泛惊吓
[ ] 删除重复的追逐、打斗和说明段
```

## 9. 高频问题清单（A01批审读沉淀，审读必查）

> 2026-09-30 第101—110章审读与复审沉淀。以下每类都来自本批实际命中的错误，写前对照、写后自查、审读复核三层都要过。审读报告命中任何一条时，必须列出章号与原句。

### A. 连续性事实类

1. **人物位置链**：每个角色每章的位置必须有出处——在场、派遣、返回、留守，四选一写明；不能在章节边界凭空出现或消失。分头行动者（少年团、信使、留守哨）和两头跑的角色（杜姨）最容易断链。转运、交接必须写出"交给谁"，不能让守岗位的人"不知何时"出现在别处。
2. **数字闭环**：人数、用工数、料钱、盐药量在章节间引用时必须能对上。前章报"用工二人"，后章对账要么是二人，要么写明"添到几人"；点名清单与总数一致（"躺着的四人"必须数得出是哪四个）。
3. **信息释放顺序**：人物没到过、没看见的信息，叙述不得提前断言。现场发现的制度信息（查验、身份、限员）按人物亲眼所见顺序释放；上章末的概括不得抢在下章现场发现之前。
4. **知识来源**：角色的判断必须有可观察依据（水垢痕、震动、磨白、排沟走向），禁止写角色"看见了"视线外的东西。限知视角下，人物自报名字之前叙述一律用"那人"，不得提前用名字称呼。
5. **物件物理**：物件的使用受自身形态限制——尺身放不进册页夹层、纸能过窄缝而罐不能、报废的接头不能复活再用。凭空出现的工具（来历不明的"手电"）不入正文；同一物件全章同名，不中途换称呼。
6. **时间口径**："明天起""昨天""同日"必须与时间线一致；角色"歇息的地点"必须与其上一动作的落点一致（在短避点歇的人不能一步跨回柜影换手）。

### B. 物理与常识类

7. **光影方向**：影子投向背光侧，光从街面往上扫时影子落在高处结构上，不落在光源一侧。
8. **能力边界**：加热、照明、供电必须有对应的热源、电源和过程。队伍无热能电池时不能"烧水"；温过可以用有水流经的管壁，但必须写出来源。
9. **感官依据**：气味判断必须写闻的动作；声音判断要有传播路径和遮挡；震动要有震源（船试喷口、泵、爆破）。
10. **人体常识**：伤员搬运体位不造成二次伤害（不倒吊、不折腿）；共用餐具不回吐；旧伤在顶撑、攀爬等用力场景中要有反应，不能在需要它的段落消失。

### C. 语言与AI腔类

11. **叙述者禁语**："这就意味着""意思是""显然""这不是较真——"等替读者翻译动作、替人物辩护的句子，一律改为人物自己的判断、可观察的细节或直接陈述理由。
12. **动作-结果闭环**：每个感知动词后面跟观察结果或明确对象，禁"看浑浊""看挂壁""对着灯转""换了两处听"式悬空搭配。写法是"先看/闻/晃，看到了什么、据此判断了什么"，不是动作清单。
13. **验证动作分工**：同一件事不得由两个人物用相同动作重复验证；先后验证者各有侧重（一人看沉浊，一人闻味看挂壁），结论也不重复用词。
14. **指代落地**："那口气""四个人"这类指代必须有先行词可回查，否则写实。
15. **"像是"限量**：推断句式"像是……"一章至多一处；同章第二处改直接判断（"有人从这里搬运过重物，不是一回两回"）。
16. **称谓中性**：不以身体缺陷、疾病标签指称人物（"哑巴壮汉"→"不爱出声的壮汉"）。
17. **用字规范**：简体正文不混入繁体（"裂縫"）；人名、物名、印记得名后统一。

### D. 篇幅口径

18. **字数**：单章纯汉字 2200—3200，下限硬性；终稿统计用纯汉字口径，不以含标点字符数替代，也不与全卷其他章混用口径。
19. **行数基准**：补足篇幅时以全卷中位水平为基准（第一卷约 100—180 行、纯汉字 2250—2560），不得拿收官章或特满的章当基准；行数靠段落与对白自然切分，不靠注水句。
20. **补字内容**：扩写只加动作承接、感官来源、群体反应、判断依据类有效细节；每加一段，事件、资源消耗和信息边界不得变动。
