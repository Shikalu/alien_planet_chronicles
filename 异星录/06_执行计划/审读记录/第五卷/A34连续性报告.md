# 第五卷 A34 第431—440章连续性报告

D355—D360。白礁由第二小岸船抵旧背水短靠，弥娅当面辨认导师。白礁原只愿闭门对读。弥娅坚持把可检验的部分带到公开桌，实际失去本次私人带读和引见。

| 核查项 | 正文出口 |
|---|---|
| 人船 | D355按实测短接只让白礁登岸，第二船两原员回另一侧可撤的背风锚位；第一船留船人仍原锚位。D356白礁随原细路到三层，与曲荻等三人分边，原号送瓶先过。 |
| 水、照护与原债 | 白礁与船员各自备水食。原三客D356、359各实换6本地壶同层可查私水；原照护、船工桶和返程封底各存。伤情、岸车、原檐及六普通包沿旧，无新净水配额或新药。 |
| 导师可证内容 | D351具名答纸在沿潮港，D355实看问项抄片，导师由弥娅亲认。D357交他一份失散问纸仅答应回港转问，未确认消息。 |
| 可复核材料 | 教学抄样不作旧档原页。白礁写自己亲见授课用旧表的范围，见证两份局部副页。样张归白礁，曲荻持旧航页和一副，弥娅持另一副及原载体，闻汀自持窄签。 |
| 版本差与留白 | 两岩与表号段能对，教学样可指第一放绳岸端，在用页同处没这行，印边与栏线也异。样不能给原潮水位或完整测深基准，没证明印次先后、谁删改。铜套图及薄折页分记约170年前跨域封闭与距开篇16年前栈城本地旧事，原件各回干格。 |
| 下一篇可用事实 | D360原上返者实接五层检索窄联，还没有实收。D361可先看三层已有经手抄纸，后续上层证物须见回条与实际权限。 |

## 最小场景补充，供作者核阅

第二船按既有已验短靠办法作一次新窗口的现场试接，未启扩航。新增导师带来的教学样和局部可核副页，只承担版本差线索，完整原始测深和删改经手仍留后。弥娅失去的是本次能实际兑现的私人带读及引见，无提前官方处置。
