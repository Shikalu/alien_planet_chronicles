# 第五卷 A40 第491—500章连续性报告

D412—D423。原退夹人实转北面小港，林渡与曲荻走第二船旧水路实返栈城。弥娅保留自持旧声片和可继续复问的人证，随后在沿潮港实收潮庭首次正式叛徒判决。卷末两岸各自确认的事件不同。

| 核查项 | 终稿实际出口 |
|---|---|
| 人与副证 | 491白礁走有引护的短阶搬临位，林渡在同一内港窗取回自己的纸带摹记。493原退夹人实抵北面小港，继续留北；林渡和开夹小工次日实返，带回实到联。原读台纸带未移动。 |
| 船与航水 | 第一船仍在沿潮港扣泊，原船工仍守；一帆两长桨已扣，动力件未拆，私粮和D402日用罐另于原封底。第二船用自己票买一封罐处理水，D418实装出海，四人按现场准出，原封底不动，先换一根帆脚短系绳，途中损一块旧护板。D422林渡和曲荻实登栈城，两原员退外锚。 |
| 栈城实收 | 同陆原车停运、原号照护和原岸资源边界续存；三层实际收三种副件，曲荻留五层借出原签和附回待实归。山口收到林渡到岸待递短报，无当班跨海回音。 |
| 澜陆实收 | D422封匣由潮庭公船送沿潮港外台、驻台公文经手亲收锁存。D423桑佑在驻台及当事人前核印开宣。原件归驻台，值守、护岗及候泊经手按己职责执行；弥娅当场失去原本实际可走的内港护送、申诉受理、官方归船登记。 |
| 许可与下一班 | 白礁和两港工等四人的本人联继续按各自实有权限；弥娅仍可由外廊民间人路撤走，原声片和档件仍自持。栈城、北面小港和其余港口未实收判决；未形成已获准的常设粮药线。 |

本批补写的具名宣告官、送件实收和分窗撤记，是对C01当地执行方式的场景细化。判词所列指控由潮庭提出，既往港方施压仍按当时权限记。没有改变原伤病、供水口径、C02历史分期或灾变揭示次序。
