# 《异星录：断阶之城》全量读者审读·批次B

## 批次 / 章节

第一卷第026—050章，共25章。审读顺序：先单独通读本批正文并记录首次阅读能够确认的信息，再对照《第一卷前100章逐章卡》《世界规则与地理》《栈城路线图》《角色圣经》《角色出场与语气卡》《关系与成长线》《人物状态台账》《资源与时间台账》《伏笔与悬念台账》《事件与地点时间线》。本报告只记录审读意见，不修改正文、章卡或共享台账，不提交 Git。

当前工作区正文相对 Git 既有版本已有未提交修改。026 旧稿第63行“她选择留下，意味着之后每一盏水都可能成为敌我分界”的抽象主题句，在当前工作区已被鸦母挡回水桶、继续按住阀柄、林渡转身抬担架的动作场景替代；本次按当前工作区正文审读，不将该历史句列为待修问题。

## 读者一句话理解

林渡带着伤员、孩子、工匠和黑布信徒留下后的余波，从废弃货运坡道经维修缝、木闸、承重平台、升降井和断阶旧路继续上行；他在水票册、伤员、房车和父亲留下的路线线索之间不断做取舍，并与祝衡、弥娅、阿九、杜姨及三名孩子形成更明确的共同行动。队伍随后进入议会仓库、公开澜陆身份、遭遇黑潮教团夜袭和门禁封锁，最后在无水、房车可弃和官方入口关闭的条件下决定攀外壁绕行。

## 严重问题

未发现已经证实的硬设定冲突、越界揭示或会使本批主线无法理解、必须暂停后续正文的严重问题。

以下问题目前不升级为严重，但需要后续兑现，否则会升级：

1. 第048章身份终端连续称林栖“已撤离”，而她在场受伤、领取水票册并写下实际位置。当前正文把它呈现为可追问的系统假状态，不是作者误写；若后续既不解释为旧记录、错误状态或制度性抹除，也不让它产生现实后果，读者会把它回读成连续性错误。
2. 第043—050章的人员口径可能被首读理解为“原登记34人始终等于现场总人数”。第043章前后有新增二层居民，后文仍出现“三十四个人”的说法；目前未见数值硬冲突，但若正文没有明确写“原登记34人”和“现场总人数”的区别，关系配给、伤员和撤离顺序会变模糊。

## 中等问题

1. **第026章：方位参照在车、人和坡道之间切换。** 第41行先按观察者视角写中间槽、右侧铁轨、左侧水声；第51行写“车走右边，人走中间。左边封住”；第75行又写“右侧是山壁，左侧是蒸汽井”。单独看每句可懂，连续阅读时读者需要反复重建朝向。建议改为“靠山侧、海侧、坡道内侧、坡下”等稳定锚点，转向后再重新定位左右。
2. **第027章：动作主体“灰手套”承担了手、戴手套者和墙后人的多重指代。** “灰手套立刻收紧”“灰手套让开”“灰手套把木盒扣回胸前”既可能是手，也可能是人物。首读能知道墙后有旧维修者，但很难稳定确认此刻是谁在动。建议在不揭身份的前提下统一为“墙后戴灰手套的人”“那只灰手套”“墙后人”，避免手部与人称混用。
3. **第028章：解释性总结多于可见动作。** “林渡不能只等他再作一次决定”“木板挡住光，也挡住了祝衡的视线”等句子把人物刚刚完成的判断再讲一遍。祝衡留在门外的行动本身已足够说明拖延，建议删弱抽象解释，把效果交给巡灯、命令纸、水线和修复后的门缝承担。
4. **第030章：裴叔死亡前后的主题句过密。** “接过册不难……才是杜姨没有办法替他一次教完的事”“裴叔还睁着眼，他便不能先把这场撤离办成接遗物”“不能用多停一会儿假装自己还能做点什么”连续解释同一层道德意义，削弱探脉、等呼吸、先抬活人的动作冲击。保留其中一处沉默或器物动作即可。
5. **第035章：发现一处明确病句。** 第29行“只用手背挡住阿九伸来的手握”不通，读者会卡在“挡住……手握”的搭配上。应直接修成“只用手背挡开阿九伸来的手”或“压住阿九伸来的手腕”。
6. **第044章：广播信息与群体反应偏整齐。** “异星污染源”“盐湾的潮声”“未知武器”等内容集中进入广播，随后多人恐慌和弥娅继续看热流，容易显得像用一段广播统一推进所有矛盾。建议把反应拆到具体人物的手、眼和器物状态上，例如谁重新系绳、谁收起水壶、谁不再看仪器，保持群体分裂是由动作累积而成。
7. **第048章：伤情动作与后文连续性需要持续确认。** 本章同时写右手掌水泡和保险片划伤，伤势会直接影响后续握绳、扶梁、写票和传递工具。当前没有与人物状态台账的硬冲突，但本批后续若让右手恢复完整功能，会成为连续性错误。

## 轻微问题

1. **第026章：比喻密度略高，环境物性偶有抽象。** 蒸汽、冷凝水、盐垢和沉渣总体区分清楚；“像”“仿佛”类句式可再减，避免坡道每换一个危险都配一次比喻。
2. **第027章：高风险文风指标最集中。** 该章比喻、否定句和短对白密集，虽然信息没有跑偏，但“不是……而是……”与短暂顿句连用会显得像模型在推进论证。建议保留最有用的两次否定，其余改成人物检查器物、报数或让路。
3. **第028章：对白短促且段落切换频繁。** 人物语气有区别，但大量短句会让祝衡与年轻护卫的追逐段节奏发碎。建议在关键命令处接入门缝、灯罩、枪背和命令纸的连续动作。
4. **第030章：重复确认死亡的节拍偏长。** 探脉、听呼吸、贴近口鼻、再等片刻连续出现，且每步后接一句意义总结。可保留一个动作，以水票册封皮、蓝布线或抬担架的人收束。
5. **第032章：木质承重描写很具体，但“裂缝—刻纹—旧交通路线”连续信息略密。** 首次读者可以明白木尺藏线，却不容易同时记住第二齿、半组记号、潮时和井壁嵌条。建议在下一章重新指认一次“已得到什么、还缺什么”。
6. **第043—044章：专有称呼的公开节奏较紧。** “澜陆人”“污染源”“异星”在同一段广播环境中连续出现，容易混淆是谁在命名谁。可在每次广播后安排一个人复述或误用，帮助读者分清制度广播与居民传言。
7. **第048章：终端文字有效，但“已撤离”解释延迟。** 作为悬念可以保留，最好让人物当场只确认“这与眼前不符”，暂时不追查原因，避免读者误以为事实已经解决。
8. **第050章：拆冷却回路的代价明确，但房车情感收束略快。** 阿九摸车门、空碗和炭画轮子的细节有效，可在后续检查一下是否有动作承接，不要下一章直接当作普通物件遗忘。

## 设定冲突

1. **未发现与已发生事实硬冲突的世界规则。** 026—050中的房车无电、绳索不足、材料消耗、升降井失控、热管改接、门禁身份逻辑、旧轨频率和冷却回路限制，均未越过当前技术、能量与材料边界。
2. **水资源账目一致。** 第039章取三壶，第041章丢一壶，第045章一壶分别用于伤员和回路，第049章最后一壶分完，第050章整壶为零；湿布、冷凝残液和车内冷却液没有被写成新增饮用水。
3. **人员加入与队伍规模基本可追溯。** 第035章确认少年团和获救居民加入，前文约二十四人扩为约三十四人；后续主要按原登记人数叙述，未直接写成“现场只有三十四人”。
4. **人物装备和权限未被恢复。** 祝衡的短枪、身份、钥匙与签字权始终受限；弥娅的仪器仍受精读和屏损限制；阿九的接头、冷却器和房车分别经历损坏、临时修复和拆除。
5. **第048章“已撤离”不是已证实的设定冲突。** 正文明确让林栖在场、受伤并以水票册写下实际位置，状态与终端不一致本身就是情节矛盾，而非作者忘记人物位置。是否把它定性为错误记录、旧状态或制度性抹除，属于作者后续决定。
6. **34人口径仍需作者决定。** 如果“三十四个人”只指原登记队伍，建议在后续第一次再次出现时补一个“原账”或“含新入册者另计”的可见对象；如果指现场全体，则第043章后的新加入人数和资源分配应重算。

## 建议直接修正

1. 第035章第29行先修正病句，不新增情节：将“挡住阿九伸来的手握”改为“挡开阿九伸来的手”。
2. 第027章统一墙后人、灰手套与手的指代；保留匿名，但每次动作主体必须是一个稳定对象。
3. 第028章删弱“不能只等他再作一次决定”等解释句，把祝衡的拖延落在命令纸、灯罩、水线和门外站位上。
4. 第030章保留裴叔死亡确认中的一次关键动作，删弱其余道德总结；不要让旁白替读者完成全部意义判断。
5. 第044章把广播后的集体恐慌拆成三到四个具体人物动作，避免所有反应都通过同一种“害怕”来表述。
6. 第026章在关键转向处改用稳定方位词，至少保证“车走哪一侧、病人走哪一侧、蒸汽井在哪一侧”连续可追踪。
7. 第048章后文每次涉及林栖右手时，明确她还能做什么、不能做什么；不要把灼伤和划伤写成一次性的描写。
8. 第050章若后文仍让房车出现在队伍记忆中，应保留阿九或林栖对车门、接头、冷却液痕迹的连续反应；若不再回收，则应在本章明确它的物资与情感账已结。

## 需要作者决定

1. **第048章“已撤离”的制度含义。** 是终端使用旧数据、系统按上报状态错误标记，还是议会刻意把仍在场的人归入撤离名单？三种方案都影响后续水票、身份和幸存者名单，当前不能替作者选定。
2. **第043—050章人数口径。** 后文“三十四个人”是原登记队伍、实际现场总人数，还是已经被制度固定成一种便于管理的旧账？应在章卡或正文中确定一次。
3. **第027章旧维修者的匿名边界。** 是否要继续用“灰手套”作为阶段称谓，还是尽快固定为“墙后人/旧维修者”；这决定后续读者能否把父亲工号线索和当前人物对应起来。
