# 第021—030章读者审读报告

批次 / 章节：
第021—030章《被占的冷凝站》至《水票册》

读者一句话理解：
队伍在东侧停用冷凝站争取有限清水，发现水量按上行计划被扣除、维修记录遭篡改；他们沿旧维修路线躲过巡查、穿过第二道木闸抵达交换市后方，裴叔在撤离中死亡并把水票册和断阶旧图交给林渡。

读者能确认的地点与人物目标：
- 地点依次为东侧停用冷凝站、电池仓、三层废弃货运坡道及旧轨、维修缝、第二道木闸、交换市后方和三层坡道上段。
- 林渡的目标是取水、护送伤员、保存维修记录和水票册并避开巡查队；弥娅负责局部热流判断；林栖负责维修与记录；阿九负责无动力房车；杜姨负责分水和名单；裴叔负责交接公共账。
- 读者能理解测潮仪只能读取局部热流，无法预测人的选择；水票有互助会和议会两套账；房车已无可用热能电池，废储片只能短暂驱动车体。

严重问题（初稿）：
1. 第022—023章水箱数量曾不一致，已统一为单箱，并补充六份基础配给、分发、巡查带走与泼失的换算。
2. 初稿的局部水量与全局账面无法复核，已补充水票账按基础配给折算的说明；资源台账同步记录为全局约62份。

中等问题（初稿）：
1. 第029章接头动作曾越过技术限制，已改为无电状态下的机械楔紧。
2. 第026章两条路线汇合不清，已补充担架、车门板和旧轨道的汇合点。
3. 第028章祝衡对影像风险的判断曾过度深入，已收束为“上传后追捕扩大到跨街范围”。
4. 第030章裴叔死亡过程过快，已补入抓袖确认水票册交接后才停止脉搏的动作。

轻微问题（初稿）：
1. 第021章“门把另一侧的人”已改为“门后的人”。
2. 第025章电池仓回路动作已通过门锁、备用回路和旧线槽上下文补足。
3. 第023章已明确精读只消耗一次，并把平台窗口写成有限呼吸数而非精确预言。
4. 第026章已补充两块储片的快慢差异和两次短移的动作结果。

设定冲突：
- 正文只称灰手套一方为旧维修者/黑布后的人，没有直称“无面者”，符合设定揭示计划中无面者身份事实应在第43—100章展开；第27章章卡已改为“身份未明的旧维修者”。
- 角色、资源和伏笔台账核对后，主队二十一人、另三名本地伤员、累计五人失联，裴叔死亡并交出水票册，弥娅第023章消耗一次精读、剩三次，房车电池归零，均与正文一致。
