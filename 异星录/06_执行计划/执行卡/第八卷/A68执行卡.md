# A68 同时开闸的人

本篇承诺要让两岸实际联动，中间交付新测位、双岸复测、核心接入及可独停的联动手续。局部验证会减少可用工时和转运班，放弃未经验证的宽开方案，交下篇的是带余温与守班义务的工程，及仍需搬移的住户。

| 章／日次 | 视角／地点 | 目标、阻碍、选择、代价及钩子 |
|---|---|---|
| 771／D765—767 | 林渡／西院后岩坡、料棚 | 徒手走新点退路，弃窄位，借料试架，护栏耗工；新观测位能否取到旧尺同深。 |
| 772／D768—770 | 林渡／西院干栏、观测台 | 旧样和借来的两筒同深对读，拒用偏筒回填旧数；可用替筒找到但两岸没有同潮段，派封件。 |
| 773／D771—775 | 林渡／高货路、三层封架 | 弥娅留岸负责点位；林渡找迟棠、阿九及本地车班。新借期由持权人实签，连水库检修道仍不通电；留一次运输资源给照护。 |
| 774／D776—781 | 林渡／残水库检修处、三层 | 核进出水路，废旧连通路；约隔离专用回水、先手压试；核心用短段人力移入山侧检修间。 |
| 775／D782—786 | 弥娅／西院 | 双岸各留闭位重新测，实收东岸来源及一处超界，读数不能相减遮过，划掉拟继续的第二档。 |
| 776／D787—793 | 弥娅／西院与本地传递 | 两边各有否决权，将联动约在同一潮相、各岸按本岸实读分开停，遇失联先闭守；换掉单方印准，双件实际送达。 |
| 777／D794—800 | 林渡／残水库检修处 | 试核心、水库旁路与回水读，留住独立民水；发现回口承托不足，借修理而非从住户拿板；推迟迁居货运。 |
| 778／D801—805 | 林渡／残水库至三层交口 | 带载但海闸闭，两处负载反馈，撤掉膨胀旧接管；用地方能停的手续交给具名工，确认核心废热到检修回流。 |
| 779／D806—810 | 弥娅／西院 | 两岸预签与本地工况回实；按旧取消的空窗、最终候窗、命停可独走明确；安排温测岗与备用引路人，缩庆典与迁居趟。 |
| 780／D811—817 | 弥娅／西院与回件席 | D811两岸及核心分地完成首轮，停后各守；D817东及核心记录实齐，只让已验证的档位按窗运行。余温与高处转运走向A69。 |
