# 执行计划与验收证据

接写章号、故事日次和最新返修以 [状态导航](../../harness/status.json) 为准；当前要做什么见 [详细执行计划](详细执行计划.md)。写作/返修流程不在本目录重复定义，统一使用 [项目Skill](../../skills/alien-serial-harness/SKILL.md) 与 [Harness操作](../../harness/README.md)。

| 目录/文件 | 用途 |
|---|---|
| [详细执行计划](详细执行计划.md) | 当前任务、实际接写边界与卷间约束，不充当通用操作手册 |
| `工作区/批次ID/` | 仍在进行的写稿、修改和审读；发布后清理已完成正文副本 |
| `执行卡/按卷归档/` | 已执行的写前卡，按历史方案留证，不作为当前状态 |
| `审读记录/按卷归档/` | 初审、修后复核、批次连续性报告；保留真实审读过程 |
| `连续性审计/` | 每50章/卷末审计、开写验收 |
| `发布验收/` | 正式发布验收记录，非待发布缓存 |
| `设定决策/` | 规划审计、批准/待定事项及处理依据 |

已发布正文只保留在 `异星录/正文/` 的唯一版本。工作区不是已发生事实来源，历史报告里的“当前、下批”也只指该次截点；实际事实按根规则读取动态台账与最新已发生记录。旧章维护的批次证据、去重去向和历史版本说明集中见 [维护证据索引](../../harness/maintenance/README.md)，不把旧整理报告当作当前任务。
