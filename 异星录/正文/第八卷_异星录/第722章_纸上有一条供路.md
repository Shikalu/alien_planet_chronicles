# 第722章 纸上有一条供路

递件成人回来时，脚上的干布磨穿了。第六百四十五日日光落低，他从山门走到值台，把一片闸署回签放在桌上：“准你们到检修院。没准动闸。”

林渡先让他坐到主人今日准借的短凳上。唐荻将回签外套拆开，递件人指着自己留在背面的几行脚程，逐段说清这五日去了哪里。另一个成人没跟他一起返五层，仍留西岸交接院，等他们是否实际去的回话。

第六百四十日，两人在五层实接路抄及林渡、弥娅封好的有限会见问件，下到四层内阶高石宿。次日到三层原交口，旧低路不再用，改从靠山高货路绕出。第三日止在西岸检修院外的料棚，第四日才见到当班领料人。原图指的旧门已经封死，新入口在石槽上方，若照图走到海侧，便走进无人答的卸水沟。

“我们没替你们多领路。”成人说，“只问人，问哪份准条能让人来。”

递件人又把外套里一块小木牌拿出来。牌上刻的是料棚接件号，只作引到院门的凭记，不开闸。到高货路岔口仍得有留守成人来接，他们若迟到，接人者下班就不能拿空牌往里闯。

林渡问岔口哪一边还能歇伤者。成人报靠山废料檐下有主人新准的一处坐位，海侧板铺已经受潮，不再认旧画的两脚宽。他自己在那里靠墙过夜，听见卸水沟的水声隔着下方石槽，没见到海峡水面。所画路线到院门为止，远处的军岗和轮边都没走过。

唐荻按他的口述在旧抄上划掉海向岔线，留了未走记号。林渡肩上伤着，不能到门前才发现夜宿只剩湿板；他请回件成人再转问坐位能否给弥娅留伸腿处，未获答前不加第二个躺席。

回签署名许铎。纸上写他现任西岸检修闸组的值闸官，借出本组原记录中的两段可核摘要，同意林渡、弥娅及陪行成人入院看检修段，不授开闸或军用外层通行。附来的还有闸署原领料人的签，准条要在院门对当班交接簿核，不凭这张纸自行穿过海侧岗。

蓄水主人也到了。他先看回签，再看林渡，问旧军方掌的地方是否肯让供物者报价，或已经把供路给了自家熟户。

唐荻将另页展开。领料人认过两条现用路线，一条经军方外料棚，一条由地方车工在高货路交短料，两条都止在检修院，不认跨海。后者的短料每批验收，欠料可以另找供者；前者来的整轴件仍需原军方放出，许铎不能擅自转卖。

主人用指甲划着两条线：“这一条运水近。到你们这片远，送同样六壶，我的人要多歇一夜。若都只看壶数，我永远输。”

“路和搬工也记。”林渡说，“但不把以后都归你写进去。”

主人说自己还怕一个问题：约了出水，临时又叫他把供水人换去修梁。林渡将“送到为止”写入待谈栏，交物后若需别的工，另问本人。这才让对方将清单摊在桌面，没有再捂着。

主人将清单放在自己手边，问谁接到货会签收。六壶和两捆干柴若成交，要由自家两名成人分趟送，先供五层眼前有限核问与短护；它不能替检修院许整场工程的水，更不抵受护者人名。主人愿留这项报价到他们出发前，没有当场送水。

罗芹从晾场过来，指着桌侧一叠新接收条提醒唐荻，本片前日已续借与续任到第六百四十七日末凉，日光落低后的梭工时段保留。第六百四十一日借期到时，他们重新问了住人，没等林渡回来盖准。

“有个代表换了。”她说，“下棚的人自己议的。你们别往远处一去，回来又照旧找原来那一个。”

唐荻请她把新接话人的位置在回读板上点明。林渡听着，将自己计划不在五层的日次单列，没让听证的待查与住处议事混成一行。祝衡与槐七部分交付的缺项还留值台，核问三人仍按各自能借到的时间接话；原夹寄存到第六百四十一日的期限已过，管簿女人出示昨日实到的新同意，只续到第六百四十八日。

受护簿未跟那两段闸图一起装出。蓄水主人看见包仍封着，没再要求开包查保护谁。他只问实际用量记录会不会给自己一份，管簿女人答若新批成交便给对应用途与耗用抄，不给整个受护名簿。

存水间本日另准八壶民用水，成人实送到晾场，二壶交照护，六壶入灶。此前四十一日至四十四日没有可核的新公共灶入水，住户以各自私壶过日，不能把私人互借算成补齐了全棚；新六壶今日用二，余四，罗芹以自有准烧边料续火。

林渡回晾场时，夜护妇人抱着孩子在母床外侧坐，原缺的补觉地仍没有新席。她问他去外面是不是能带更大一批水回来。

“这次去核闸。”他停在盖板边，“水若没准到，不能拿回签兑。”

妇人说知道，却将自己的半壶往孩子那边移了移。林栖守完本段过脚板，接她去原有窄休处坐一会儿，没动罗母的床。林渡留在灶边等，听短边料烧裂的细响，没有再说整城终会变凉。

弥娅在他身旁坐下，将坏测潮仪装在原包里。它仍不能读数，这次不借许铎的准条假说已经有完整数据。她带的是可核的局部湿图和旧声片所存材料，哪些能给闸署看，须按当场用途分开。

“他们问我是不是潮庭的人。”她说。

“回签怎么答？”

“准来的人。不是被恢复的人。”

林渡把这句另留在出发条上。去西岸至少要在四层、三层各歇一夜，再走高货路绕行，陪行人从本片自愿成人里问，不抽林栖守板，不借还坏着的原车。返回的递件人愿带第一段路，另外两位成人答能陪过四层，原有重活换给本片实际接班者。

回到值台时，原路信已经封妥，但一名陪行成人还没有答应。他原来次日要替下棚修支脚，问林渡此去能给几天期限，若迟返，下棚不能一直等他。

林渡撤掉了原拟同行三人的总数，等下棚另一名成人实际接了那一段修脚，才重新写入两位愿陪到四层的人。过了四层，一人原约止步，另一人陪至西岸；留西院的递件人接高货路。各段没有多出一个免费搬夫。

唐荻只送到四层，她要返五层接自己的路口事。林渡把轻夹交陪西岸的成人，坏尺仍自己系着；弥娅原包不交供物者，也不让少年团夜赶未验过的高货路。多带一个人要有吃水和回去的地方，今日问不到便不添。

那片回签在桌边被风掀起，背面出现第六百四十二日的收件记号。闸署另认过一条现用递件路：西岸军方检修服务艇可在下一条件航次带一个封包，向海峡东侧检修闸组转问。许铎只准代递，不保证对岸收，也没给弥娅同行位。

递件成人从内袋取出原艇接件副条：“第六百四十四日清早，留西院那位沿高货路把先遣问件送到三层交口，我还未离那里。艇工实接，他给我这份副条，自己回西院候接。”林渡让他将交接处指在路线边，东岸收件栏仍空着。

临行约定定下时，主人又回桌前，在六壶与两捆柴旁添了自己的准出记号。这一批自愿供五层短核，不索回工，交付截止第六百四十八日末凉，不续到别处；以后若交易另签。他要管簿女人把自愿两字念给旁听人听，免得日后又被说成无偿供全部工程。林渡请记实际送达，未到先不列库存。主人拿着自己的副页走了，桌上仍没有六只壶。

林渡收起出发条，右肩因久坐开始发紧，便慢慢起身回旧板。明日他们去检修院，但真正要谈的那张桌，至今只有西边一个座位有人署名。
