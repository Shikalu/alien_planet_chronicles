# 第六百六十八章 三个地方各有一张停条

迟棠见纸上有个停字，叫候托的人退了两步，顺便让抬工把两副空铺退出了上车道。来传话的人立在三层石肩，举着末尾一字问为何连放车的都停。纸是从上面来的，从五层下四层的成人交来一张抄件，上一格空着，带纸来的人只好照末字念给他听。他鞋缝外一圈黄泥，此前已经在弯里等过一趟瓮，想拿空套子置换一下。迟棠没看出哪一层当值，只见从石阶下来的裤脚有水。他自己也不放开停车处，吩咐回的人先把纸放在这里。

第五百九十五日，林渡早凉随三层原领路工绕过一遍三层接石到同陆岸台的退处。抬人可走的第二鞋都还没当场画过，塔那边先来了这一纸。就迟棠接条时落的那一道短记，他能辨出收到时早凉已经在末段，写字那时是否刚开须问执笔人。撑纸来的原成人还要回身去问谁让他带下来的，林渡捏住沿风斜下的单页，指对岸等车的那处纸角，让他留步。湿汽贴岸台栏面铺过来，天色下这地方正好是等车一点的旁侧，踩过留出的石槛便进了候托人的肩线。传人皱起鼻子，按住自己腰包里的那条湿袖子，先说只听那人念了一个停字，随即沿肩退向脚下干处去。

“车不走。谁在车边先回迟棠，纸问到哪再报哪。”林渡把原要论塔那边是否该停的那句话压住。他问自己本来要带的两副空托能不能回到靠山的试置石上，让地面成人照迟棠刚叫的停看一次退步。远侧原尾工先给石肩回掌，确认车尾未偏出原来候位。迟棠实守原刹。林渡在车侧能看见两头的干石角，请原工班的中继亲报尾工那一掌，车头这才复述收到。林渡站在石肩能看到岸面偏暗的一个小角，倘若绕上四层内阶直去塔门，这里原拟留空托的人便没有纸，等下一道的水号叠来时又要临时找他站在窗边对数。他向值工要一根压纸的石，没有从石肩离开。

林渡托人去三层交口查送件的来源，曲荻让一名只当这一段脚程的人下来，先把上一站点换纸的人问清。那人原约拿的是走空手回五层的问页。林渡现在改请他走四层旧修台，看抄纸的经手者若上头还能应，务必由他本人添完整的站位。停字照前，不为找原字在热时抢上塔。另留一张三层原地停车记录给离点的人，让他们把原刹、车上无人、暂不抬空托过车侧这三项告诉这头。有人看见“无人”以后还问两位已经候在附近的病人算在哪里，值工朝里面旧交口供候的两个软铺位指，说实候地面，人原照护仍在，没有去车上。把背上的箱放下来再看，这两托连同后来可能过来的衣物都还不能拿进原车扣眼。

午后热意在石壁里沉一阵，末凉才开内线。带字回来的工人从四层内弯下来，裤边晒干了一圈。他说抄的人在旧修台侧歇过，记的是五层外缘塔的回墙上栏。上端试温遇白汽顺岩脚偏来，帮抄温筒的灰裙工在五层回墙内给轮手叫停，未下筒，没湿数。这轮没有可给下头换轨的同时时段。他在三层交口把那句话请原接件成人再念一遍，经手人说的是外墙停测；等到车来岸台的内口，他对迟棠把同一句念完。中继在立柱外侧把“外墙停测”复述给原尾工，又替尾工向车头问本地能否卸挡。迟棠边把刹握紧边回话：“挡照留。这里还能摆空托，出车没有我的许。”抬托的成人单收近地此时可以摆空托，但等过一次原停口亲见，没得出车号。

还有一张塔背的回条跟在充当压纸的薄条里。原仓工把仓锁未启、手泵仍合分为两行，照旧由原工按实际锁位同接水口看见的人共验。下一时段若外墙仍看不清，只守闭仓和原槽，不把装车等人催来的话套成过闸许。抬那一回短漏之前遇到的回水与此地走近尾绳的条件都要另认。林渡请读纸的人将它放远离车场的这张，免得有人再取近字当口令。围着的老车工抬起一条很窄的凳，隔着暗木试往三段中间摆，迟棠给他报两个本来分开的站位，凳头若斜过干石边，原尾工向回的手被坐的人挡在背后。几个人抬退两回，石肩上那石印终于从雾里露出来，两个空托可以慢一步挨近内沿。

林渡请一路递条来的成人朝五层带回车场实况。站在三层上转口的人看见回条上一串站名，伸手逐处比给同伴看，忽然问工人听到这些之后可不可以在三层值桌代原车头签复开。他把迟棠眼下守的地方指一次，从未离原轮，没到第一石口，更没到卸载端。塔背只须记回从这里听到车仍停，车眼前需要的一道弯由三层守轮段的人自己写，接段人实到再往下一笔。两个回条只写收到，哪只筒归温、哪只仓开、哪只轮走都各留原岗。别人跟在内阶跑一来回，至少少一只肩能在同一时给人抬水。能把五层这两页接回去的今天只一人，真有哪处贴海吃紧先处置，请下一班再留跑件而不要等他同时出现在各处。

带信的人在石肩扎了原来的袖口，一直别好湿布。他说方才有人从四层新卸载棚到近山转，托下次回话顺便捎蓝衫的花结。蓝衫主人昨天托问的人只见到被问那位上到五六间内拐口，还没找到本人，纸可给她回在棚口。林渡正想把旧人见过的什么写一行，发现这一页是从三层车场再往上回的，经过四层却走不到桥的另一头。他让添一句纸暂留旧修台，等桥两端有人实接再入棚。这样不能当家里在三层有一项见证，折去问原人留岗的日子要再记。传人这回只带两张透风也不会从袖中滑出的窄纸，家话沿旧阶下一段按实际经手另存。林渡用左掌把车场收两条那一侧压了一下，左掌麻归麻，没把三份叠起来。

要到对面侧槽去看退脚的原尾工回来，带泥杖靠在车场外肩，伸手朝近处一指。今天车尾旧枕木的炭线还与昨日石面一边齐，水落过止木侧痕，退处不再靠湿阶。车边抬空托的一人等着妻子从上面换岗，听见换人便朝岸上喊，说他的肩还能接到末凉。原尾工没有应他出发，蹲在干凳边把挂着空托的长布尾都收回案后。前一班那个会抬瓮的右肩顶了半日，没有一双手能从塔门同时伸到这里。林渡让候托的人看他前次把手伸错的石沿，此刻不去那头接回，原来许这一个空托进位的人也得当众再走一次退路。硬要问下次能否先上两副卧托，只能等今凉和下一段都能看出干的那几处实际踩过，车未发就有人要求从这里退下去也不能用轨侧空脚。林渡跟迟棠说，先请明早两组抬工把两位候者叫到这边，请照护人亲带托扶的退脚再认一轮，第三副候托仍留原候位，由自己的照护人守着。有人急着从石肩后跑进来，手里拿的竟是下一班将抬的人自己写的两行字。他把纸口一偏，迟棠才看见字的下方压着他的汗，一行说从原铺下船时肩动不了，一行问停过一次，人留车上还从哪一扇开着的门出去。
