# 第六百六十三章 零刻留白

第五百九十三日，靠山内门刚许人从塔背出来，林渡便看见一团湿气掀起方口上方的破布。外缘塔回墙的上眼仍露出半块发白的石，湿气是从下面卷上来的。弥娅托着东船温筒，隔栏垂出去一段绳。刚才她指给他认的岩窝就在栏外一肘低处。绳一偏，筒身错过岩窝，在墙石上撞出很轻的一声。

弥娅自己将筒收回干石上。外壁只有一面沾水，筒底留下一道竖直的黑砂，边缘同昨天老工人给他们看的地方一样粗。留在栏边的塔工脚心没过干刻，手原来准备接她往回拉那一把，此时只帮助把绳尾在柱内拾起，不往外跨。他问照这次筒上的刻数先填着行不行。上一个收簿的人回屋等了半日，原本为了抄给替手明天认地方。若青线边没读数，外头候搬的人看不出这条路可不可用；他给守门的抄回一个空处，待搬的人准会自己凑过来问。

“撞在墙上。”弥娅把筒正面转开，“位置错了。记撞了哪块石。”

林渡在栏内找到视线能擦过旧眼的那一道缝。回墙向山怀凹，可伸手的地方是坐在干石边，脚挡在旧栏底，外面还有一处低的小板口，他先前没有从这边看过那头。低板过去的旧槽沿带着成条的黑硬粒，贴里一侧的方口下眼一团团冒白，原来标下的试片点还要近两道挤紧了的石缝。再向外半肘，同先前水向山拧相反，一股水从岩沿贴壁往下淌。林渡用左掌摸到近侧石面，还带凉意，便沿塔门到栏底数了一遍能踩的石面。隔着回墙，他摸不到那股水，也看不见它从哪个眼头流来。他第三步想用下边那根横栏借力，抬头发现方才绳挨过的石就在栏脚前侧，水上来时先到那只手。于是他把退字旁自己曾添的第二笔擦掉，只留下从内门后的岩面撤。

他们看的是从喷口方向来、能影响到塔和近岸承托的热水，不是沿海每处同时测。原工班保留有旧图，在五层值桌对过照图能认的旧槽和回墙。弥娅想把后来守在岸侧那班人与塔背这头用的几条水迹分开。去年那只已碎了读数盘的测潮仪，旧档仍在包里，开盖也指不了哪一块眼头在升温。这轮可重复校的，是放在同一截干石上时，沿岸工原借来的温筒与她从东船带回的那支是否仍差一格。两只筒本来就差一格，下一班只见高值，容易把换筒读成水温升了。干处重新比过，能留的也只是这次两筒的差数。她让林渡先帮把栏内这处出入和入水方向记在纸上，眼下唯一一次湿读留空。

一个穿灰布裙的中年女人从内门过来，手背一道白粉，是刚在下头洗过空瓮，原洗瓮水还留在石下没往塔里合。她在干岩袖口向里翻，摊开一张有水痕的纸，问今天看的绕坡同她信上那个男人在塔班时走的是哪一段。林渡见她袖里不带蓝衫，再对照纸头，只是同一桩托问由守门成人交到她手里。她说自己上热时以前来替井眼抄过物件名字，蓝衫的主人是昨晚俯在棚门说话的那位，丈夫曾帮看水壶。周围没人按名字给她送去过换手，只能经原岗查亲见。中年女人爱认每张纸的湿干，自己把回话留在夹的上一层，再从下一层取来一块平底木片，给两只温筒找坐处。林渡请她先留手听工班读，试着以后少找一个只来收纸的成人。

干石刚刚挡过薄雾，手摸上去潮，底下还残一片明亮灰白。弥娅把平板稳放在这截干石上，两筒并排搁下，抽出垫高一只筒脚的绳头。两个筒彼此挨得很近，又各留可伸指读端的空。短漏立过一回，岸上那支的线停在原先那一格，东船筒仍低一格。她手不再抬筒，叫帮抄温筒的灰裙工记明同一处干石、同一轮短漏。拿炭的人先写出来的是东船那只较凉。弥娅用指尖将两个字推到画好的筒边，指给她看这段高石上两只都没有下水。打炭的人停了笔，低头念了一句“东船筒记在低一格”，在她自己的筒位右边划了一点。这一次再见“低”，不会有人说城下的水退了。

守栏成人掀起桌下护绳的布，说干石的值还能让下一班保持原记，只要再探一回湿处，误写的一栏也有填法。林渡把短漏扶起就看见外面光线变灰。隔着这点灰，他还辨得出回墙正下方那道泡透的木边。岸班拿来一张旧水迹纸，纸上石齿外侧还相当低，原各点人准备据此继续往外。原报外石的工人就在栏后，伸手说那条线看上去还比昨晚低过两寸。林渡让他把纸所指的石齿念明白，再问墙后这一道刚转往下淌的水能不能从外石一处看到。他伸出胳膊替那人指直，两人都找不到越过墙体的角。岸班那人把旧纸移到临海这栏，自己从灰布底下伸手摸了摸外出前应该踩的第一处石顶。他手指拿回来，在裤腿上揩去一道黑湿，将自己原定再跑下段的姓名从今日那栏抹干净。没人用指上这点黑说认了水源，湿处和安全退口都有脚下实处。外水须等回撤路径上的另一块石脚露出来才够安全，再探不止费这一轮沙，还要请人从塔背到下阶窗帮看回路。本来下阶人的抬壶班就等林栖交手，此时若把她的替位抽给第二次试位，水班到时让谁守不清。轮到自己站近回来，他指了指原本打算让试温班踩的第三步。旧栏外面又响一声，有碎末从下面打上来，挂在刚才撞筒的那块石边。

“这次只交干处。”林渡说，“人从内门退。写得到的那句。”

弥娅手停在绳尾。她给帮抄温筒的灰裙工一张小纸，上面是她原抄的两个读点。今凉只确认近岸临时干基准，等到同一处真的复现条件，才能拿括号里那一格对一次。湿点变不过来，轮班的人直接改从干墙等；不用带空数去求谁批下一次开泵，外水进到哪一截，要请能站在干处的人用自己看见的标出来。中年女人顺手将两张纸用一个夹子扣牢。那个原守栏成人向她报可留一道未试位，帮后来人当面认过。林渡看见他抬脚朝最滑的一块石脚下站，下一秒便将脚放回，有人从空处拉过的绳已经深得看不到湿下去的边。

塔背墙上温度已经贴上来，亮的石面很快看不见前一阵水珠。林渡退到内门，顺看两个人在哪里能看见彼此的手。弥娅让早凉接过纸处那名妇人回屋去复述自己的站点，自己仍把绳理进兜。此处第一次有效湿读仍得等安全条件凑足。谁守着能退的路，他把这一行单留给人填。

中年女人临下门槛手摸了摸灰裙。一张细纸从袖口掉出来，尚未踩过湿槽边。是接到过的那句话，蓝衫主人丈夫留在塔门的时段已经认出来，今天不在回墙这个岗；在另一个塔班，末凉才可能问得到本人。她请林渡给自己留个叫谁的记法。窗角伸出一只手，喊塔里的量壶都到齐了，举起一张写着“塔仓”的纸，说是不是该开扣。林渡正要进门告诉他空读从哪来，看见守仓成人在里头原位伸掌，问那个把条举在白光里的人是来合柄，还是来叫他们开仓。
