# 第三百七十三章 灯过门以后

闻笛的线盘卡在铁槛外，怎么也不肯跟着人转进去。

槐七先从盖侧实石退回来，蹲下看盘沿。窄检修盖已经打开，外沿落实，旧限位链微松；人能侧身跨过的地方，线盘连着手柄却宽了一截。闻笛将盘从肩上卸下，轮缘才离开槛角，露出一道新擦痕。

“盘留外头。”林渡道，“只进线。”

闻笛抬眼看他，随后把盘安在自己带的矮脚上。外口成人站在可见天光的地方，照她示范扶住盘轴，线由手里一寸寸放，盘缘不贴湿地。另一卷先留干处，谁也没把大盘往刚认过的人路里硬塞。

两只新灯今日第一次装芯。壳上各有闻笛旧刻记，弥娅提一盏，另一盏由原台岗帮搬者持着；进门前先照各自手柄和开关，光稳才收好备用布套。原车那只裂罩灯仍在外面，旧应急芯没有拆。

三处当地成人照约到齐，交口一人、外口一人、旧小车检修台一人。帮搬者随探查队入段，到了台边才停。林渡、槐七、弥娅与闻笛继续向前，回话经台岗传外口，车旁阿九只接逐手传来的短报，不同时出现在闸边。

检修道比上回湿。槐七在前用自己的木柄拨开新落的石屑，背后吊着小线环；闻笛每走一段就将线收向靠山侧，用自带的旧软环挂在已经认稳的钉座上。没有钉座的地方，她让线沿内侧可见石脊走，不绕到轨槽里找近路。

林渡的左袖擦过岩壁，纸束便转到胸前干处。右臂吊结贴着衣领旧破口，他停在完整石窝，等槐七先走完下一段，才用左手轻扶岩面跟上。线从脚边经过时，他让闻笛先固定好，自己再跨，不踩住线替它受力。

旧小车仍在原台旁，裂轮和断片一个不少。帮搬者将自己的灯放到能照回道的位置，报清台边尚剩多少半班，闻笛把第二卷线暂放在干台。第一卷到这里已经接近末端，红线扎着的接头刚好停在台前的潮湿弯口。

“这里不能接。”她说。

槐七指了上方一处凹石，接头挂上去又会压住下一人的肩路。闻笛沿台内找了一会儿，最后用自己带来的小夹架固定在完整石边，接头能见、脚下能过，才把第二卷接上。红扎线保留着，另添一片干布挡落水，布不贴住接缝。

弥娅照她的手，光没有越过转角催人。林渡听见外口传来一声停，立即让前面收步；片刻后台岗报是居民取坛的人在外路交会，盘暂不能转。闻笛将手里线尾握在松弛处，队伍就在岩窝等，脚前的线没有被后头拉直成一根绊索。

再传可以放线，四个人才按顺序往下。

过旧维修台以后，靠轨的那条石边被新泥盖住，表面比内侧更平。闻笛原来扛货时习惯找宽处，脚尖刚朝外，林渡便报停。槐七把木柄探到泥下，露出旧栏座的一截断口；再向外，柄头便悬空，下面传来细碎落泥声。

闻笛收回脚，把自己的线换到内侧完整石脊。她没将那条看着宽的泥面画成备用路，反而在箱角加了一道系带，免得以后赶着收仪时又往外占宽。弥娅等她站稳，才把灯抬到下一阶，光照出石棱上方一层细水，前后的人都沿同样的干脚位过。

林渡站在后面报最后一人的位置。线在内侧有一处松弯，恰好绕过他的左脚，他没有抬伤臂去替前人扶箱，只将脚收进岩窝，让闻笛先把线顺直。她回头说这一段若真要反复守岗，得留一张让新来人能认的图，不能每回都靠一个嗓子在后面喊。

闸前低凹里仍有细水，黑湿沉渣压着轮槽，铁页没有动。林渡记着此前上到侧台的石级，先让槐七认外沿旧缺处。弥娅持灯照到光暗交界，闻笛将箱贴着内壁送过低拱，人随箱后，始终不站在缺角上。

侧台有天光。两盏灯中的前灯在这里熄下，返暗路还要再点。闻笛第一次看见外头的近岸水面，手搭在箱盖上很久，之后才把测温筒取出。

“岸货页记的石脊，跟这里隔着一弯。”她指向洞外，“外湾起风，里头未必同一刻退。”

弥娅让她将旧页转到向海的一面，先找能重复认回的石角。筒端不能从缺栏处直接垂下，槐七沿内岩壁找到一个旧探孔，孔下通向紧贴闸侧的水凹，站在完整石上便能放筒。闻笛先用空护筒试到原限位，取回未碰石，再把测温筒装回。

林渡报台边来话，半班已经过半。弥娅只认这处能从安全位取样，不在今日等全轮水势。她把下筒深度标到系绳上，闻笛看内柱稳定后念一回，纸上明写闸侧单次，不用它报大潮日。

两卷线末端抵达侧台，尚能留一段松弯。闻笛把闸侧线端包好，在高位靠岩处固定，不伸进原闸机。旧铭板下方另有一只小检修罩，外表的图画着手轮与方块，字被泥壳遮住一半。槐七只擦掉已经离开的碎泥，盖没有撬。

林渡看见图里的方块随轮位变化，问是不是该接线的地方。弥娅将能辨的字抄下来，念出“验位”，后面缺的字仍留缺。闻笛用自己的点验盒在外面比接口，大小接近，却没往里插。

“先找到它只报什么。”她道，“我这两卷线经不起替整座闸供电。”

台岗第二次叫退，林渡收纸，槐七转身走第一段回阶。前灯重新点起，闻笛收起测温筒与盒，长线沿已挂的位置留下，两头断开、包防潮。到了旧小车台，第二盏灯的持有人收岗，跟四人一同上行，前后光照到接续处才换步。

外口成人接他们跨槛，盘还稳在矮脚上。两卷线未用尽的一段收在干处，不作下一轮多走的路程。闻笛在灯班格各记第一次实际短探，出盖五人都站稳才熄灯，台岗、外口与交口三人逐一退岗。

阿九听见线到了闸侧，先问小检修罩开了没有。闻笛把未开的图给他看，他用钳柄压住那个小方块，说若是报位，车端可以先做与牵引隔离的接收；如果连着原闸动力，那就不能照这个法试。

麦穗将新图描在干纸上，画到长线穿过低拱的位置时，纸边不够，便另接一小张，没把弯口缩成一条直线。小石在交口听见“到了”便想添完成记，林渡让他改成线到，闸位没验。少年对着图念出两项，笔才落下。

次凉，两位原借物主实到山口，灯壳、三只借挡与好后绳又分别到约日。闻笛借来的器具放在另一侧，修轮住户先认自己的旧裂罩，问是不是从此可以拿回去。林渡说明新灯仍要跟人入暗段，旧灯留外面应急；原主看过应急芯封口，肯再留一旬，但旧轮套待修、水架改班和留借工仍各记。

好后绳由另一原主验压处，槐七守驻车，阿九留脚刹，三只挡都没有被抽走给线盘垫脚。原主认完分别填新日，晚些在三层原熟住户处歇，次凉再上四层。

林渡将新借期留底，旁边是提前去见五层旧料主的路线。他得赶在原重议日之前把线到、闸未开的实话送上去。弥娅拿起那张验位小罩图，问他若自己还没回来，闸边的实测是否照已认短班做。

他把图放到两人中间，先指出谁留在车端、谁跟着灯入段，再给四层短门画出递话格。那只未开的罩在纸上只有一个小方块，下一次，得有人站在那里看见它怎样报位。
