# 第三百零二章 一段走得回来的路

林渡离开五层时，陶继已经坐在看板位上。

原工站在他后边，核完上一班的字，才朝林渡摆手。林渡没有带走那块板。他和阿九各带自己的水，旧绳绕在阿九腰间，卡钳与短撬棍放进工具袋；随行的槐七从旁边借了一只空篓，装回程用的标记木片。照护棚的三班仍照旧换人。

通往四层的维修侧廊在灶后。进入前先向内绕过梁脚，再转向下行，墙上有旧年的箭头，箭头尾端已经被新钉的补板压住。林渡用左手扶着内墙走了几步，没照箭头踩外侧。

一块旧垫板翘起来，露出下面被水泡黑的端头。槐七拿篓压住补板边缘，林渡让他移开。这块补板只盖着洞，不承人的脚；空篓压上去不塌，不能拿来证明人也能站。

他们沿墙排成一列。阿九走在中间，左膝每到较高的踏面都要停一下，先把另一只脚落稳。林渡不催。五层传来的敲板声还听得见，再往下一个折角，声音便被热流的嘶响盖住。

林渡就在折角处停了。

回撤路不能全靠喊。槐七将两块标记木片挂在转角内侧，一块指五层，一块空白。遇到需要回话的事，由他走回这个角上，亲口把消息递给上方等候的邻段工。那名工只在本次凉时顺路接话，过了时辰便要回家换手。

阿九从袋里取出一段短绳，绕过内侧已有的圆孔。绳结做完，又把结尾压回墙缝，免得人转弯时勾到吊布。林渡看见孔边露着新亮的木纤维，便让他换了另一个孔。第一个孔的边缘已经裂开，拉绳的人体重若压上去，会连同外边薄木一起撕下。

旧绳只作路界，不能承人。他们把这句话告诉上方接话工，省得后来者把绳当成救命索。

临近折角，槐七先看到一根横在路上的细梁。梁底连着旧挂物钩，上头挂过一张矮棚的边帘。这里已经很久没人铺床，梁却仍垂在原来高度，恰好会撞到林渡伤肩。

槐七想把它向上托。阿九叫他看挂钩后面的墙：钩根只剩一条细锈边，托起一端，另一端可能脱落砸脚。他们不能一边扶梁、一边扶两个伤者过路。

林渡退回平处，指向梁外侧。外侧仍有旧脚印，但补板没有接上内墙，踩到边沿便会把人引向板下空隙。他没有改从那里绕，等槐七把篓放下，再借袋中的短撬棍从干处轻顶梁端，让阿九把原挂绳收到更靠墙的钩上。

他们只移走挡住吊布的一端，没拆整根梁。原帘绳打过结的部分脆得一捏就掉纤维，阿九不得不从随身短绳里截一小截替上。换出的脆绳收进篓里，带回去报废，不能再挂回去冒充原样。

走过以后，林渡记下此处仍不能并肩通行。槐七问将来能不能搬一只大水桶下来，阿九看着梁后的宽度，说人能侧身，桶不会侧身，先别把这一趟记成搬料路。

下一个折角，一阵白雾从低处卷上来。林渡贴住内墙，脸颊仍被热气扑了一下。雾出自侧廊下方的热水排口，墙根一道深色湿痕连到裂缝；白雾挡住踏面时，看不见水究竟溅到了哪一级。

阿九伸出撬棍，杆端刚靠近湿痕便沾上一滴水。他把撬棍收回来，水珠沿着铁杆往柄端滚。

“等。”林渡说。

槐七把篓放在身后干处，退到前一个折角去报话。林渡和阿九留在内侧，没有跨那级看不清的踏面。雾薄下来后，地上出现一层亮湿膜，踏板接缝里夹着细碎的灰白沉积。林渡让阿九用木片刮掉一小条，看见底下的木纹还在，水却仍从缝里往外渗。

这条路今天能走到哪里，和旧箭头指到哪里已经是两回事。

他们绕着湿处停在预定的中段。从这里往下，墙板开出一条窄口，能看见四层住宅外侧挂着的晾布。窄口与人之间还隔一段斜梯，林渡没有因为看见布就把这趟勘路延长。

阿九扶着墙坐下，伸直左腿。工具袋抵在脚边，刚才被水珠湿过的铁柄擦干以后仍发温。他把绳子从孔边抽回一段，磨毛比出发前长了半指。

“不能拿这段拖东西了。”他说。

林渡将磨毛处系了个散结，用作报损标记。不切断绳，就不会误以为短出来的一截仍在工具袋里。

槐七回到中段时，带来上方的答复：看板没出警号，接话工再留到这一趟回去。林渡记下白雾出现的位置，转身准备上行。

准备收绳时，槐七问空白木片还挂不挂。林渡让他收回来。上行接话的人一走，留下木片也不能替活人答应下一次。槐七把指五层的那块留在墙内侧，空白片装篓；阿九又将磨损绳段收高，免得拖在湿踏面上。他们回去还要走同一条内线，不能给后一个人的脚留下一道绊绳。

下方这时响起两次木板敲击。

一个女人站在四层短门边，用长柄竹片推开挂布。她看见他们，不跨斜梯上来，先问是哪一段的人。槐七报出五层的灶砖圈与杜姨，女人才说自己替住宅短门换手。昨日上去的那位姨母曾在她这儿歇脚，她的铺单仍留在门内。

“来这边得先说定。”女人说，“有门，不等于有空铺。”

林渡往下望。女人背后是住宅走道，旧轨所在的外侧货棚隔着一排封板，从这里看不见房车。她用竹片指了两个方向：过人的门在内，旧货道在外。要到车位，得先落到短门，再走货棚平段，不是从这道窄口直接爬出去。

林渡把两个方向分别记在木片上，免得回去的人只说一句“四层有门”。

“明天可有人接我们？”他问。

女人说，早凉时她在；热时要把门让给屋里搬水的人。来的人只准放工具，若想借一轮遮阴地，需在门外报姓名、人数和回话时辰。她还没问林渡是谁，阿九便告诉她先别把车算成能用的家当。

女人扶着门框笑了一下：“车若真能动，你们也不必站上边喊。”

她把门口一只小桶往内挪，露出斜梯末级。那一级有两道裂纹，明日若来，得踩靠墙的半边。林渡将这个位置一并报给槐七，没让篓里的回程木片挡住自己再看一眼的视线。

笑过，她把竹片收回去，在门口挂出一条细白布，留作明日辨认。

回程比下行慢。蒸汽又涨了一次，槐七先回折角报了等待，林渡在干踏面上蹲不下去，只能靠墙休息。右臂吊布的结被汗浸湿，磨过颈侧的红处。他解了外层结，阿九用干布隔住，再替他重新系好。

等到白雾退去，三人仍按原来的内侧上行，没有把见到的短门当成捷径。五层接话工最后一个离开，顺手收下他们的报损木片，说下次若自己不在，得另找人接，不能只把空白标记挂着便算有人知道。

杜姨收了他们剩下的水瓶，瓶里的水仍各归各人。林渡喝掉自己的余水，没有叫灶边补满。阿九把卡钳和撬棍擦净，搁回原处，旧绳则单独摊开晾干。

他们没有到房车。

那名姨母听完路线，没露出失望，反倒松开了布包上的一根绑带。她给杜姨看四层那张铺单，上面的换手标记和林渡带回的字一致。她说短门到三层的路也有人天天走，但今天她不拿自己的保证替掉他们的核问。

林渡把明日要办的事写在纸边：短门接话，水随人，货道另勘。

阿九靠着凳背，把磨损的绳段拨到纸旁。

“先把这根的命算上。”他说，“车还没碰，绳已经少了一条用途。”

林渡在木片上画出短门的裂级，标明明日从靠墙半边踩过。阿九将磨毛绳收进袋内，门口那块方头接头仍留在五层匣里。

四层挂起的白布只留到明日凉时末。错过换手女人，她便要关门去搬水；林渡将出发时辰写在裂级图旁，让陶继接班核完就来叫他。
