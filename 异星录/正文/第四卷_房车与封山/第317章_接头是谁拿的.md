# 第三百一十七章 接头是谁拿的

车外热起来以后，阿九才松开脚踏板。

槐七已重新推实轮前止挡，驻车柄咬进完整齿，车架与石角的接触处也没有再落砂。阿九一点点撤去脚力，车轮留在原痕上。他在座中坐了好一阵，右腿仍绷着，直到支棚人从门边伸手来接，才抬起脚。

出前门比进去更难。左膝硬得几乎不能弯，他让人把小腿托平，自己侧坐在门槛上挪。裤腿蹭过凹铁皮，发出拉扯声；林渡拿从车内收出的那块碎饰板挡住铁边，等槐七扶阿九落到石面，才把碎板放回废件一侧。

老人将坐凳让给阿九，自己回门里守着水坛。三名少年挤在石檐最内边，麦穗伤腿伸直，小石半边身体还沾着转角的泥，岑野的右掌包了一条窄布，结在手背，始终没抬眼。

阿九看着他们，先把车门残留的碎饰板放到脚边。

“谁拿的接头？”

“我。”岑野说。

“谁碰驻车口？”

麦穗抬起包布的手：“我转的。他说只转到能推，我听见响就停了。”

“止挡呢？”

小石往前挪，岑野也开了口。阿九让他们分开说。前挡是岑野抽的，后挡是小石搬的；石环上的绳由岑野解，麦穗和小石帮着提起绳圈。三个人推车尾，到了坡口，小石先下，麦穗上车，岑野把绳绕到残柱。

阿九拿碎饰板拨开脚边一小粒石子，露出底下平整的石面，又问哪一步有人叫停。

小石说自己看见下头木枕歪时喊过。麦穗说第一回踏板有点紧，她以为再踩就能到底。岑野说都听见了，是他叫再到下一根柱；弟弟在下头，他想车过去，里面的板和架子全能派上用场。

“我知道他在下头。”阿九说。

岑野手臂一抖，布带下渗出一点红。他抬头，眼圈通红，问阿九若被压着的是自家人，还能不能坐在门里一遍遍说等。

林渡左手停在瓶塞上。他见过妹妹在井里向上伸手，见过梁缝里那点够不到的脸。岑野盯着阿九，嘴唇颤了几下，剩下的话没能一口气说出来。

阿九将碎板翻到另一面，那道鞋印仍在。

“我会想赶过去。你看我这腿，我也想车替我走。”他用两根指头压住膝侧，“可车一滑，麦穗在里头，你在后头，谁还能去救你弟弟？”

麦穗低头看自己小腿，线头黏在伤口旁。她说是自己答应上车的，没让岑野骗，说的时候想把脚收回去，刚挪一点便疼得停住。

阿九向麦穗抬手，让她把伤腿搁回外衣上：“你这笔也在。”

小石望向阿九，又望向岑野，把嘴边一句话吞下去。他蹲着解自己鞋带，解开后里面全是泥，脚趾蜷在鞋里，刚才沿窄条一直没敢放平。支棚人让他把鞋放到能接滴水的石边，先挤出鞋里的积泥，别把湿鞋穿到皮肤起泡。小石照做，泥从鞋尖淌出来，落在自己先前坐过的地方。他取过老人给的破布擦掉，才再坐下。

阿九等鞋放好，没有跳过他的那一项：“你在车前，路不对，回头叫的该是我。”

石檐里安静了一阵，外头从漏槽滴下的热水越滴越急。一滴落在林渡鞋背，他把脚向内收了收，看见岑野也朝下阶口望。去送水的成人还没有回音，这里没人能替他把孩子下一口水已经喝下说成实话。

“我们把你的车拿走了。”岑野终于说。

“还有别人的绳、止挡、方头件。”阿九答。

老人从门里出来，把断晾杆放到三人面前。杆上两只晒布夹仍好好的，断茬带着新露的黄木。小石伸手要拼，老人让他别碰，杆子拼上也撑不了湿布。

“我今早要去取水，坛搁在这儿，人也过不去。你们哪一个替我抬过去？”

岑野撑着地要起来，手掌一压便缩回。老人指指他掌上的血，弯腰收走断杆，没让他真来抬。那道内侧石路的空隙仍只够侧身，坛底会撞到车壳，哪怕有个完好的少年，也不能靠一句认错把车挪开。

林渡把追车经过记在纸上，请三名少年分别认自己做过的部分。纸念到小石解没解绳时，小石纠正了，他只抬了绳圈，没有解结；岑野认下解结。麦穗又补自己转过两次方口，第一次没转动，第二次换了手，才听见棘齿声。

林渡在纸上补进两次转动，将各人的名字写到亲手做过的那一项旁。纸递到岑野面前，他指着解绳那行，按下左手拇指。

阿九没有伸手接纸。他摸了摸自己袋中的旧钥片，隔着布把它按到更里面，转而让槐七将车门上能随手操作的维修盖关好。往后他们可以在成人旁边学看件，暂时不能单独摸制动、接头和牵绳，何时恢复，得等伤好以后重新练停令。

岑野问是不是不让他救弟弟了。

“跟队。认人、说话，叫你递什么再递。”林渡答，“撬梁的手现在用不上你。”

少年把右手放平到膝上，指尖慢慢松开。麦穗听见暂时不能碰制动，脸转向石墙，过了一会儿才说自己记得踏板下面那片板在哪。阿九叫她画下来，之后要查脚槽卡住的原因，这一项她能说清。

她用左手拿炭，在纸边画了窄槽，边画边停，指出自己先踢了哪一侧，另一侧怎样钩住。阿九看完，只在她画出的断口旁添一条线。那块饰板原来失了固定，他也该在试移后彻底移走；他将这一项落到自己名下，再把纸推回。

小石问绳怎么办。老人门外那段绳正搭在轨肩上，滑柱时磨开的长须贴着泥，原先浅白的一处已经露出内股。槐七挑开绳皮看了受损范围，系上废用记，留能完整辨认的一段与原结分开卷起。长绳不能继续认作牵车好绳，原主还得看到实物。

“我做工还。”岑野说。

林渡问他能做什么、哪班、伤手多久能用。少年答不上来，只把那句再说一遍。阿九摇头，将断杆、绳损、车壳和借工各画一道，工时另留空。先认损，实际怎么还等主人到场，不能拿他将来十个做不到的工班换今天一句算了。

说到吃水，小石将自己的瓶子抱紧。老人看他一眼，把手边空凳移开，给他靠墙的位置，没开口要少年交瓶。林渡让各人留好本班份，晚些若不到下一处补水，明日便得先停工接瓶。岑野弟弟的原份随刚才那位成人走，三人当下吃喝各照原名，抢车的账另记。

热时最亮的那一段，谁也没有再下轨。老人允许他们在石檐侧边歇，门口与水坛前的半步必须空着。槐七坐在能看见轮子的地方，支棚人替麦穗挪开压到伤腿的衣角。阿九眼皮垂了几回，最后仍张开，盯着外面那一角车壳。

岑野挪到他脚旁，问现在能做哪件。

阿九把那片踩折的饰板交给他，叫他先拣出断边的尖钉，放进同一块废布里。岑野用左手做得很慢，小石帮他压住布角，麦穗只负责报看见的钉尖，三个脑袋终于不再各朝一个方向。

林渡出去看回路。车尾上方的烂台被绳扫掉，沿原轨上拖，后轮必须再压过那一段空边。老人跟到门口，问是不是很快能把车弄回去，明日他还要抬坛。

林渡顺着露空的台脚看了一阵，返回来时，将写着回车的那行划了条横线。要往上拖，先得在悬空处补出一截能承车的路；他们手中那根借来的短撑，还在去塌棚的人肩上。

阿九看见横线，撑着凳沿坐直：“回不去了？”

下弯的热水正绕过卡住的轮子，浸到老人门前。林渡将纸递到他手边，叫槐七等热势缓一点，先一道认山口方向的短轨。车不能堵在这里等上头补齐整副台架，往下也得重新验，没人还能照着少年留下的轮痕走。
