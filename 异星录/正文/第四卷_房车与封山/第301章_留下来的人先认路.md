# 第三百零一章 留下来的人先认路

第二天，林渡没能按原定的凉时出发。

五层靠海的看板位空着。老陈把昨夜的记录压在砖下，手指仍抵着最后一行。他答应守的是凉时，太阳越过棚脊以后，得回去换家里的人。林渡若从这里走开，护板后那道裂缝便没人连续看着。

陶继站在两步外，提着一只空凳。原先握长柄工具的手贴在裤缝上，掌根那层旧茧已经开裂。

“我能坐。”他说。

林渡没有立刻把凳子接过来。外堤停岗以后，陶继一直留在棚区，工具收在原工手里。昨天公开桌上的运输记录也没改变这件事。愿意替班和知道该看什么，中间还差着一次交接。

海风从护板下穿过，带来晒热的木焦油气味。陶继把凳子移进阴影，背后却挨着旧支架。林渡叫住他，示意往内侧挪。那根短撑的受力位置没变，脚下两枚旧楔也没动，不能为了坐得凉快，把凳脚塞进撑木退让的空地。

“先认退路。”林渡说。

他用左手指出看板位后方的窄道。窄道通向棚内水桌，途中经过两处接水盆，第一只可以移，第二只垫在漏棚下，走的时候必须绕开。陶继走了一遍，在转角被挂出来的凝水布挡住。麦穗把布卷起半幅，露出下面少了一格的底边。

“这一边今天能过。收布时我会喊。”她说，“别自己扯，底还没补齐。”

林渡在木板上画了三条短线。一条对着裂缝下口，一条记护板螺栓的位置，另一条记水盆沿。不是三种同等的险情：裂缝变宽要叫原工，螺栓掉屑先停靠近的人，水盆里的水忽然连续晃动则先往棚内退，不能在板前蹲着猜原因。

陶继把顺序复述了一遍，漏了“先退”。

“我能看清再叫。”他说。

林渡解开吊布的颈结，往里面塞了一片干布。右肩被束着，抬臂的念头一动便牵到伤处。他没有再画，把那块板递回陶继。

“看不清的时候，也得叫。”

陶继低头看自己新写的字，擦掉最后半行，重新补上退路。

热时开始前，原工来了一趟，只准他坐守看板，不准动护板、松螺栓，更不能凭这里的替班去领外堤工具。陶继听完，把原先拿来的长凳换成了窄凳，留下通往水桌的路。他问能不能把自己的名字写进当班格，原工让他写在林渡下边，注明初次跟班。

林渡仍须留下。

第一阵热风贴着板面上来，水盆沿泛出密密的细波。陶继刚想扶住盆，林渡已经叫他离开。两人退进窄道，老陈去请原工。半刻后，原工查到外侧一块晾木被风吹动，撞在护板上，卸下晾木，水面才平静下来。

陶继站在窄道里，手上没有半件能把自己留在原处的工具。他问，若自己独守，也要这样把整段的人叫退？

“先叫离这块板。其他人听原工。”

棚内有人抱怨午饭因此迟了。陶继没有辩解。他回去记时辰，把“看见盆晃”和“查到晾木”分成两行，没把后一个结果提前塞进前一个判断。

到下午，他已经能说出林渡离岗后谁来接话。再下一次热时，原工会在邻段干活，听到陶继敲两下木板就过来；若原工被调走，这个替班便不成立。林渡把自己的名字划到明日的勘路栏，留下了今天的空白。

杜姨在灶旁招手，让他过去。

岑野的弟弟坐在干地板上，膝间摊着一条旧布带。杜姨把他原号下这一班的水搁在脚边，让岑野认过，再往旁边让了让。现在孩子面前多了一名女人，衣摆卷着干泥，脚边放着两只扎紧的布包。岑野蹲在弟弟旁边，没抢着开口。

女人先叫了岑野小时候被叫过的乳名。

岑野的下颌绷了一会儿，才说：“姨。”

孩子把布带捻成绳，递到女人手里：“你以前给我缝过这个。”

女人翻出布带内侧一道歪针脚，摸了摸孩子的头。杜姨这才给她让出半张凳子。

姨母从三层靠山的板棚过来，两个凉时才走完，途中在四层住宅短门歇过一轮。她说那边有亲属留下的一张床，离海侧漏棚远些，想让孩子过去住几日。她这次带来的不是通行令，只有沿途换手人写给杜姨的到达条，证明她确实从那条路走上来。

“不是搬过去不回来了。”她说，“他夜里一咳，整棚都跟着醒。我那里能隔一张帘。”

弟弟用指甲刮着布带上的结，没有应声。

杜姨没有把孩子的铺卷递给姨母。她先问他愿不愿意去，孩子望着棚顶漏水留下的黑圈，说想睡个不会滴到脸上的地方，又怕哥哥找不到自己。

姨母把刚坐下的凳子往外挪，和孩子隔开一点距离：“你不去，我明天帮这里晾布。去了，也只住几日。你哥哥找你，不用靠猜。”

岑野伸手想收弟弟膝上的布带，孩子压住不放。他收回手，说先让林渡认路，谁也不能今天把铺卷背走。姨母答应，将自己的包放到杜姨指定的墙角，没有占掉孩子原来的睡处。

灶边的水盆被人碰了一下，孩子立即缩脚。岑野看见了，蹲下来把倾倒的盆挪正。他弟弟曾被锁在一扇不能自己打开的小门后，这一回，下去的门要能从里边推开。

林渡把这句话问给姨母。姨母说三层板棚的门闩在内侧，外面没有锁；屋里那张床也不靠门，出门到短廊只隔一层布帘。她说完，将板棚的简图画在灶边废纸上，留下床、门和屋外排水沟的位置。

孩子在纸上指了指沟，问夜里要不要跨过去。姨母说屋门这一侧有平板，过沟是去别家，不是上自己的床。林渡留下图，没把“有床”当作其他问题都已经回答。

岑野问三层是不是已经能下车。姨母摇头。走的是居民过人的支路，山腹那条主隧道仍封着；有两段转角窄，只容一个成人侧身。她来时见过推小车的人在门外拆下轮子，人先过，车留在四层。

林渡把到达条平铺在桌上，用砖角压住。墨旁留着一小点湿泥，途中换手人盖的手印看得清，路上有没有别的危险却不能只靠这张纸。

“我先走到四层。”他说，“那边得有人认你下去的路，也得有人在孩子到了以后递话回来。”

姨母没有催他。她从包里取出一只空水瓶，瓶颈上还绑着旧号带，问孩子的水能不能随人走。

杜姨把瓶子留在桌边：“份还是原来的。哪一班发，谁交给你，都要对上。没到手的水不能先写成带走了。”

孩子终于开口，问岑野去不去。

岑野仍只跑半班递话，不能在两头同时当差。他先看了一眼林渡，又蹲低一些：“送到短门。我再回来。你到了，让姨写条。”

“写什么？”

岑野捡起那条布带，在旧结旁边打了一个松结：“写两结。别人不知道你会把第一结打反。”

弟弟试着拉紧，反结歪到了外侧。姨母把布带收回他掌心，没有替他纠正。

晚饭时，陶继拿来初次跟班的记录。林渡看见退路那一行被手汗洇开，陶继已在旁边重写，没有擦掉原字。林渡留了这张板，明早原工核过以后，才算交班完成。

他把勘路要带的旧绳放在门边，没有去取五层那枚方头接头。阿九坐着挑开绳上的旧毛刺，膝下垫着卷布。两人将绳子翻到最磨损的一段，定下明天只走到侧廊中段便回。

灶火熄后，弟弟来门边看那卷绳。

“先知道怎么回来。”林渡说。

孩子退了一步，露出门槛。他没有再问什么时候走，只把打了两结的布带留给岑野，让哥哥等回条时有个对照。
