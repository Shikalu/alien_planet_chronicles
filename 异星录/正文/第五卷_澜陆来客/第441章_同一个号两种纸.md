# 第四百四十一章 同一个号两种纸

林渡把两张抄纸夹到板上时，外沿的一张短了一截。看棚人以为他夹偏了，伸手要把它扯平。交口的值岗人用木镇按住下角，指给他看那条旧折线。

“就抄到这里。再往下，原处是破的。”

今凉从交口能带到货场的仍是昨天对过的两张抄纸。铜套大图和薄折页各在交口干格，哪一张从哪处描下来，纸背有值岗人的记号。他也跟来坐在桌旁，等人要问原处在哪里，再把自己的那行写出来。送去五层检索的窄联昨凉才交第一手上返者，回纸的格仍空着。林渡把那个格留在桌边，没有请弥娅先写一条他们还没收到的话。

货棚外的板缝已经干了一边，向里那侧仍有夜雨存下的泥。值岗人把凳挪到能看着图也能守住纸边的地方，等弥娅从旧筛旁走来，才让两份原抄转到她面前。她带着自己照样描栏、经白礁落名按印的那份局部副页，自己取出干纸套，另外在看棚人面前说明只能翻哪一侧。曲荻也来了，旧航页在夹内，她请舵手先把昨天那两处岩朝向放在桌上给人指认。舵手把自己的布卷往里滚了一圈，只露高岩缺口和向里的石阶。

值岗人先认出靠左一道叉的位置，告诉林渡那是早期跨水域的封闭记号。薄折页是栈城本地后来用过的，两张纸哪怕都在一块木镇下面压过，也不能把一个的年份补到另一个的空格里。弥娅在另纸上把两段日期分开，在对照区只留下曾给岸边一段线路记过什么号。林渡认得自己上回在岩石上见过的缺口，图边那些旧字还得问人。

货棚另一头，一个等领回木楔的护货人听到舵手说第一根绳在两岩间，提着自己的旧扁篓走过来。他把篓里的草绳挪开，从底下抽出折成指头宽的一页。纸角压了层蜡，伸手一摸，碎蜡落了几点在桌前。他先问旧折页下沿那个号是不是刚才所说的货坡口。

值岗人把两张抄纸拉远一些，请他从自己的页上指。他指到左下一个窄小的框，说前些年仓里换过抬具，给护货人发过这种小页，说明领东西要去哪个口。这一页印的是近岸后仓用的，原领抄的人还在棚里看板。他后来领了自己的挂签，说明页就让他留着，哪日老货架再拆，好照原先从哪一口出去找回一只空框。

“现在有人凭这张发货？”林渡问。

“早没那处发货的岗了。我拿它垫篓底。”

护货人捏着页角，没把纸交给别人。弥娅问他可否照着对两处看，等看完仍由他拿回。那人摊开手掌压住纸边，先让值岗人也瞧见蜡下压的是哪个旧记。林渡看见那条数字前半段能和薄折页旁的索引相接，底下却多了一小横，挨着仓里后来钉过记号的地方。

弥娅按住那一行，沿三张纸一个一个读能认的字。沿潮港的现用航页在两岩之间那一段的表号后留一小横，旁边直接列深浅；白礁的教学抄样另给第一根测绳从哪侧岸放留一行。护货人那页用的是栈城后仓的印，只有派货要认的段号和一条另行问旧册的窄注。那段号的头几笔同薄折页的索引相接，末端的划法却不一样。林渡将木镇往近处挪了一寸。几张都能用的纸，各把原先的人要做的事写给他看；现在把纸拿到另一处，空出来的地方便真的有人站着等。

棚外有人从这张桌旁搬走一段空货架，架脚擦过石槽，卷起一团黏在底下的布丝。护货人伸手去稳自己的页，蜡上又掉下来一点碎屑。他说这里搬架的人早换过几拨，那会儿拿抬具的地方却没那么多，一张小页到了错的架下，连问的机会也没有。林渡请看棚人暂且把架脚留在干槽另一边，自己将原来那两张用来对旧历的抄纸向山侧移开。架抬出去后，桌面才有够三方并看的地方。

舵手将布卷上的岸线贴到后仓小页边上。号头相近的那一处，在薄折页索引旁还跟着一个小圈，后仓小页将小圈移到了段号底下，旁边没有留叫人从哪里放绳的地方。船上用的现行航页也有圈，但圈顺着岸线走，不能挪到印字的段号底下算同一个东西。弥娅在空纸上各描一次，用各自原来横竖的方向放，不把三个圈摞起来。

护货人见她另外描线，伸出一根指头问，能不能先叫他知道以前怎么领架这几个字还在不在。弥娅带他看到蜡下原来有的短注，曲荻向后让开自己的纸，说她今天只核版本，不会让外来人拿着他的旧领用页过城里的门。护货人收回那根手指，往桌上吐出一口气，把被自己掌汗润软的折边拉回干布上。他终于肯将整道小横让他们看完，还指出自己从前折着塞篓时，折边就压在这一横上。

“这一横怎么到了这里？”林渡问。

护货人用指节敲敲篓沿。“这我说不清。仓里的人叫我看哪一格，我就去那一格抬。发下来的这页在我手里，底下那份大页归看板的人，我只在柜口望过一回。”

林渡本想问那些抄纸把哪一句挪没了，听见他只在柜口望过，就先让他在自己的记号旁落一笔。他认的是到哪个发件处领用、谁交给他的，抄的时候有没有看过原表，留空。护货人怕自己的旧纸给按了什么手印就收不回，想了片刻，叫林渡另找一张纸，先将他愿意说的事写在那里。自己那张得带回去，他还要找原先的人看。

曲荻没把沿潮港的页往前推。她问弥娅，刚才那一道横若认作印次，是否就能说港里和本地抄过同一份表。弥娅拿手指挡住版尾，给她看在用页上没有旧仓那道收件印。现在号头相近，两处岩能相对，栈城后仓这页的手记所指还得去问。这会儿只有两个地方各有不同的抄样，也各把一栏留在外边。若想认同一底表，需去找那张前后有人签收的纸。

护货人抬起自己的扁篓，正要走，忽然又想起一件事。他从小页边掸掉一点蜡屑，说以前去那个柜口等装货，值守人会问手上的纸是哪一趟抄给谁的。自己那一页下角曾有一道斜折，拿反了就找不到后仓的记。管柜的人有时一只手按着底稿、一只手往外递纸，最怕拿走那张旧的。他不知道现在还有没有大页，但曾看过的人可以去交口问。林渡把这句也写进去，没写作当日就有原表可看。

人走后，货场叫第一趟出工的人已沿着棚墙走远。值岗人请林渡先收一侧，不能把两张可看的原抄压在桌上留人翻一个凉时。他把木镇抬起来，底下贴住一小片湿纸毛。他用干布一点点捻掉，才让林渡将对过的号和另待问的那一横写在不同纸上。下回有人来只问一个号，用不着每次都摊开两件原抄。他要回交口接换手，弥娅将她那一份副页也收进自己的套。曲荻见林渡仍在桌上画那条小横，捻住旧航页外沿问他，若真正找到了当地领过原表的人，要不要先请他来这一头看旧航页。

林渡望向还没有回条的五层检索栏，把护货人小页上愿意留给他的出处另抄一行。那个看过柜里底稿的人不用等上面的回信才能开口。他将压在桌脚下的木镇放回值岗人手边，自己带着新问纸沿坡往外走，先去找护货人说的原看板人。
