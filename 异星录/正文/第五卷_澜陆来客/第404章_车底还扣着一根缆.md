# 第四百零四章 车底还扣着一根缆

拆架铺来收东西的人问，另一根长缆在哪里。

林渡朝海那边指了指。山口原坪看不见岸台，中间隔了条弯进去的岩脊。收具人弯下腰，手指塞进脚边缆卷的绳眼，提离地面一点就放下了。入水磨过的那段早擦洗晾干，挽在最外头。他从凸起的绳股上捻出一点硬砂，放在自己的借单上。

“这根能回。”他说，“岸上那根呢？”

“还扣着车。”

跟来的两个抬具人把木杠放下。这是拆架铺约定收回器具的日子，今凉肯来这么多人，是因为山口到棚里还有一道上坡。光两只螺顶就得分两趟抬，再加缆绳，须趁路板没被热气熏软时过。闸岗刚从干端取出起端长缆，肩上留着一条压白的布印。再晚，两个抬具人就得给铺里赶另一单。

“那就去解。”收具人把借单夹回腰里，“你们把一辆车留在那里，今天才告诉我车和缆得一块儿拿？”

“用了两只短挡。一根缆扣独立石锚。车回不来，挡和缆再借。”林渡把停运纸转过来给他看，“你先去看看。你自己决定。”

收具人没碰那张纸，先叫一个抬具人把已经到地面上的螺顶抬去贴墙放好。槐七在那边清垫木，从最上面一块厚垫下抽出断木屑，递给收具人。木屑是卸废架时挤进垫面里的，还嵌着一道灰皮。铺里肯收这块用过的厚垫，前提是看清受压面是否崩到边上。收具人把木屑留在垫上，同伴托着木杠，他在磨损处画了个圈。

林渡和槐七领收具人、来收宽盘管的邵砺，从闸前走干侧细路下岸。第一处窄缝只够人侧过，第二处底下有道积着咸水的石沟，跨沟时右肘容易擦墙。林渡用左手托住吊带的下缘，等肩膀从岩壁的凸起处过去，再把脚跟收回来。海面升上的热雾在外侧岩面凝水，一滴滴砸进沟里，他经过时看见前一日留在踏处的木楔已经鼓起。往外带盘管只能两人分在窄口两边换手，不能有人背着宽管还去跨那道沟。

岸台的房车停在原来的朝向，朝山一头略高。阿九坐在车门内伸得着工具的地方，左腿垫了一卷用旧的工衣。车门口两只本地借来的短挡贴着轮，台端长缆系在车架受力耳上，另一头从离车一段的实石锚绕回。收具人顺缆走到锚边，见绳身在过石处有包护才蹲下，隔着包护按了一下。

“这绳我还得给人吊东西。你们拿它扣着一辆不能走的车，出事先要算我这根。”

“现在它是留车的第二道。”槐七从车头让出路，请他朝轮挡下看，“那层石皮昨夜刚脱。眼下两只短挡沿轨一前一后，各防车往一头滑。撤掉一只，那一头就只剩独立锚上的长缆牵着车架。等它一歪，另一头的轮也得受力。那时你解缆？”

收具人探身看了看短挡外的落屑，没伸手动它。林渡能看见屑底干、外缘湿，刚露出的断茬还没结硬壳。

“你能把车拖上去，照起价给。”阿九拍了下腿边的车门，“咱们先说人力，你出几条腿？我左边这条算抵账，往哪里抵随你。”

收具人抬眼看他。阿九把压在膝前的检轮纸拿过来，磨沟处还夹着从原车旁捡起的两点亮屑。他解释车轮靠那圈金属在引轨上稳住位置，强拉时磨沟若卡上，车会偏着压住轨缘，缆够长也拽不回一辆歪车。收具人捻过屑，问换件到哪儿了。阿九把纸往回收了收。

“借过来比的那只差口。能等到合尺寸的，就写个日子。”

收具人站起身，鞋跟向后一刮，停在车缆避让线外。他没拿起刚才那支画圈的炭，先问沿海来船若要用绳，这根又算谁的。车底的绳离水近，整条新路没通，来船若肯给好价，拿它去救一次急也有人干。

“车挡两只和这根续二十四日。”林渡伸出左手，手指在两张借单中间隔开，“用途给你看着写。到时候有车件就当面验归，没有车件再问你。靠船另找索。”

“我来查护缆的布。磨到里面，哪天发现哪天叫我，别拿盐垢糊住。”收具人拿出炭，纸在风里翻，他便按在鞋面上写，“你今天往外开那条人路，得叫我的人先走。带回去的东西，过缝不等迎客。”

他写完续期，留了一份给阿九。绳仍受在原锚上，挡还贴着轮。两个工位让出一条手臂宽的地，邵砺蹲到车外宽盘管前，把收管的软套打开。宽盘管停用几日，摸得出铜面已经同车壁一样凉，原大匣仍隔离。阿九从门内报关口位置，邵砺才松开两端的接环，让低处管段剩下的设备水流进他带来的泥黑线罐。罐里第一声响得空，水沿壁淌下，出来的末几滴带一圈细锈。邵砺盖住罐，把来时备下的堵头给阿九，原回路两口各有一只，留着防止灰土灌进去。

“原来那只细的呢？”邵砺问。

阿九拉开一小块干布给他看。小盘管收在原来的地方，缠口纸仍干。他盖回去，把跟膝一样怕湿的工衣抻平一些。

“等真的要试，我再求你把大个子借我。细的挂回去也开不了车，还多一处进灰。”

岸棚帘下露出孩子那只原号瓶。刚才人来回说要收要还，孩子托着瓶朝车这边张望，瓶底在托面的木边磕了一声。阿九回身，把车门朝海的一边合到留气的窄缝。姨母伸手扶住瓶，只挪到孩子胳膊使得上力的位置，孩子没从托面起来。

搬盘管过缝时，林渡退到前方明处报脚点。槐七在沟这头接重量，邵砺留在另一边护住突出的两个管口，两人都站稳了才往缝里送。到宽处邵砺重新接回，顺着有天光的路带管与封罐上山口，去棚里当面交收。林渡在后面走，右颈一圈磨得发刺。绳子没移，原车连车轮都未转，他回头依旧看得见阿九先前描在轮前的那道墨痕。

原坪的验收赶在板面发黏以前结束。拆架铺点了螺顶两只、手拉链具一件、方木与厚垫各两件，连撬具、锯、起端长缆一并收走，磨过的面在单上留下位置。四层来的原主对过封记，提走封存的三挡与好绳，照原签收回灯具。闻笛将留用到今天的借具逐件交还原主。两盏作业灯和小匣前一回抵棚，已有回条。昨日补过能又从棚里领出，今天按新一笔借用当面点清。她把收讫纸放在林渡手边，借过的光归各主，收发箱今天不上能。

等借物人过了外口，交口送瓶人才从上面的路下来。瓶筐放地时有一只空瓶碰了石头，发出清脆的一声。林渡看见他先取空瓶给原守口人过记，再从底布下摸出折得很窄的两张纸。四层换手记在外面，五层祝衡桌的实收写在内侧。前几日那张只抄问答与会面条件的纸，由送瓶人送到四层，四层上行的人带去五层后托回了实收，今日才交到山口。回条末尾只叫日后接人也按旧路报实绩，别把来船的水先写进原支路份额。

林渡把实收钉到交口的副纸底下，空瓶筐从身后抬了过去。原来开口前抬过去几只，现在照旧数，每一声磕响还是只碰出一个瓶底。

槐七见他取下昨日画的靠位纸，问还有几根能留给船。林渡在车和锚之间原画过一条线，那里挤得下两道标记，只曾写过一笔绳。他把笔画加粗，把车缆与留车的两挡圈在一处，然后将纸折回靠位那面。来船那一头的黑点边什么也没有。

“去货场问。”他说，“肯借绳还得有人肯担它断。明早请管公用料的人跟我一起下岸。”
