# 第四百二十八章 东西还扣在车上

收具人把借单放在石上，说他今天原本是来拿绳的。阿九将车门推开半扇，门内那截铰铁才抬起来，贴着轮子的短挡就显出一个湿亮的角。

“先别踩。”林渡说。

收具人收回脚，顺着他指的方向看见岸台边一绺咸水从岩缝钻出来，恰好把轮前几块石子冲得干净。今天来还东西的人多半在货场外头等，只有拆架铺要的两只短挡和一条台端长缆得走到这里才能见到。林渡趁干侧的道还有光，从山口领他过两处窄缝，进到岸台靠山的一面。昨日暂停拟扩的货路后，等在交口问何时运货的人少了。阿九这辆车还留在原来那块干地，谁也没能替它换一处不必扣绳的地方。

“先看轮前的记号。”阿九说，“挪过的话，我认得。”

林渡靠车侧站定。他看见前轮旁的炭划被水汽熏淡，线尾还贴着同一个轮缘缺口。短挡前头积的盐粒有大有小，湿的那圈没越过挡脚。另一只短挡防的是车沿轨向山内错，两只挡各吃一个方向，离开一只都得重新认留车的办法。林渡把这个位置让给收具人，右臂照旧吊在身前，弯腰久了吊带便擦颈，他用左手往上托了托，没有伸向任何一块挡。

收具人沿着台端长缆走到石锚边。他指给林渡看露在包护布外一寸的白折，说是上回查过后自己折在那里的。外布正朝海的一边发硬，按下去能掉出细盐。收具人问可不可以解开来摸里股，阿九当即摇头。两只短挡照旧在，绳此刻仍有力，谁也看不见解开包护会不会牵动岩边那一段。收具人低头站了一会儿，最后只把手移到不受石角磨的外缘，在那里掀开半个指节宽的布边。

露出的麻股还能逐股分开，没有破到起毛。收具人把布边压回去，用自己那张借单背面记下只能看见哪里。他说本来想把这一根拿回去，铺里有人等着吊短梁，上一回借去开山的人已经把另一条还了，有两个活只够排一个。林渡顺着地面望向外边，那一卷接船公用索仍有自己的干处，和这一根不通账。早先割掉的旧备用缆也拼不成任何一条整绳。

“你今天收绳，车先停到哪儿？”林渡问。

“要是能动，推过那段平石就有个干一点的地方。”收具人伸手朝山侧指。

阿九没叫人推。他把一张纸从门内工具袋抽出来，展开一角，露出上次量坏轮时压出来的半道黑圈。哪边磨出沟、哪边还保得住，图上各有一个粗点。那只导轮没卸，也没有合口径的替件。他请收具人离轮一步，从干处看看两头不一样亮的那一圈。收具人刚说上回跑过，阿九便把纸折回去。

“上回才跑出这样的沟。你给它搭绳硬拽，它往缝里一歪，人得去轮旁把它拨出来。我左腿伸下去容易，上来得请你把我也吊一遍。”

收具人没笑。他看了一眼岸棚的门帘。风在帘脚兜了个鼓，旁边的托面隔着帘布露出一点平直的木边。来时经过岸棚，林渡见姨母在低台边晾刚换下来的布，孩子仍在原托面上。收具人先问这一带要是拉车，伤护棚的人往哪里走，再问林渡，难道每次到期都来摸一回绳，日子就一直能往后排。

林渡记得上回还宽盘管，经过最窄那一处，槐七得在沟这边守着重量，邵砺守着管头，两人隔着石棱一点一点换手。绳卷比盘管能转弯，也得有人抬。上次还起端缆，拆架铺自己带人从闸前抬上坡。这一根真有一天能卸，他该先认自己在哪一头来接。

“续二十日。”林渡说，“这一期内若换到可验的停法，送两挡和缆回铺由我认人办。等到那天仍不能卸，你先到这儿来验，不续就另找实挡实绳当面换。明天能找到的东西，今天先不写有。”

收具人从腰里拔炭，在石面上又画了一条短线。到期若要查，他自己来看；包护布一旦露出受压那边，阿九托来岸台的当班成人捎话，别等他来掀。至于以后送回的一趟脚力，他把归处与经手另写一栏，林渡看清约的是卸后送返，才用左手慢慢落名。这次确认仍只给岸车留位，绳继续在石锚上受着，短挡也没有挪动。收具人把自己的副纸沿折缝塞回腰里，没再说起吊梁那一边。他却没有立刻上坡，先请阿九让自己看清车窗上留的停运记号。阿九把车门内夹着的纸转给他。最下面有三只炭圈，少导轮、回路未接、匣未补能，外头的人哪样能帮着问，就看这张。收具人用指甲把纸上的湿角压平，问能不能照这三样给铺里做活的人说一声，哪天若有人把一只尺寸不明的废轮拎来，他也好叫人先把尺寸量明白。

阿九看见他收笔，向外台伸了一下下巴。

“你还有好几只眼睛盯这车。刚才那位问今日还能不能搬两箱，我叫他去看你们贴的停运纸了。纸上没有‘什么时候能开’，他回来又问我一遍。”

林渡把新的续借纸移到车门下够得着的干处。旧检轮纸在阿九手里，改动的只有借期与送返责任。阿九抬手摸到吊绳那一折，问料主会不会因新来的船放宽日子。林渡说得先见人，旧单并不在车边签。

原来守车端的拆架工从岸棚方向回来，接看车边一班。林渡等收具人走在自己前头，一同循窄缝上闸前，再由外口转到交口。石沟里已多出半指水，去程蹭在吊带边的湿印这时凉透了。收具人转去原坪领自己的回程人，林渡独自沿坡到货场上方的交口。旧四包的料主前一凉从五层下到四层歇脚，今凉又由四层换手带到这里，手里捏着上次重问的旧联。她从低凳上站起来，见林渡没带货，倒先把凳子往阴处拨了一脚。

“海上拿来的一包，说进了棚。”她开口道，“到你这儿谁都比我们先走？”

林渡想了一下她问的是哪次，才告诉她，那包药是来客带来的，岸棚用修架的工换了一包，提瓶的人沿细路带到岸棚，车轮没转，货也没动过旧运单。另有外人拿自己的料换水的事，仍由各自经手，不向这张单冲。料主将四个空圈一个个摸过去，问既然车不走，靠来客那条岸船能不能顶上一趟。

“那条船才试过一次新测线，没进外边。拟扩的班昨天撤了。”林渡说，“你四包有多重，哪一段由谁接，从哪处搁下，都得有能验的货位。连新停靠点还空着，我拿什么给你重排？”

料主把纸重新展平。她没有马上肯延，把自己来的几段道一一道出来。五层到四层借了宿位，清早接她的人来时还要帮另一家提旧篓。下一个到期日若照旧跑，得先给她一句哪些货能提来，不能次次把身上的旧联当成到场的货。林渡请她和交口成人一起另认二十日后再问，能验的车况先实报上去，至于纸到五层没有，等回条再记。四包继续在原来次序，今天一包未兑。她这才自己落下重问的日子。林渡把新条夹在旧单旁，两个借期恰好同日，谁的字写在谁的纸上，两处都没混。

料主收纸时没走远，在交口朝向山脚的那面停了一会儿。远处岸台与外水之间隔着岩脊，从她站的地方只能看见岸上收掉的布。她问林渡，昨日那条货路究竟是到了哪块石头才不肯让人走。

林渡翻过用来记实测的抄纸，岸侧在这里画了一个止步的钩，边上还有一处空着的测点。他把两处指给她看，发现这一份只写了谁量过，那张和实测未能对上的旧航页究竟是谁交到船上的，纸上还没有一个能叫来问的名字。
