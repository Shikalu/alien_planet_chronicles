# 第四百五十九章 同一个封套

第二日早凉，值守台安排的引路人将三人送到发页案才走。读表人坐在案后，翻到那一日的领取行，叫弥娅向另一边站一点。她后面还有两个人要取今日近港的水记。桌上新印的纸压着一块冷木，木面一遇汗就浮出一层湿光。弥娅站到案角，把曲荻请认的号递了过去。读表人取来一块小木条抵住字行，下面露出同号的两个小格。一个指向他当日交给曲荻的页，另一个叫他回去问上一手。上一手的格里只写底抄由旧架发，不写领的人。

林渡跟在弥娅旁边，听她问，是领的时候本来就没写名字，还是后来发页的人照着去掉了。读表人把他的取页夹摆正，叫她看这一张当班用的纸是怎么打格子的。发给来人之后，只留给谁、什么时刻和从哪一格取。若自己亲手从底表抄下来，另在台底收一小联，上面有抄人的名。那日给曲荻的那一张，他只从旧架递来的夹里取出，并没动笔改里头的字。

“递来时你见到经手人没有？”弥娅问。

读表人从木条下面抽出指头，去摸这一行右边的夹边。那截纸被后来的凭单叠住，拽出来太用力会撕掉前一日的。他把先来取水记的两人请上前，每人留一张领用签，等案前空下来，才从后头解开压纸的细带。他让弥娅直接看有哪两处各有字。第一处是他自己这一手实给，第二处只留旧架收回一联，贴着教用夹下数第三格。他将日子、号和这处柜格给弥娅抄过一遍，余下那本不由他开。

林渡问白礁，从这里去旧架要经过谁。白礁指给他看发页案后斜的一扇窄窗，那里的光比外头暗，窗下摆着送完纸回来的空夹。按他的领用签，一张先从那儿递进，等有人喊领的人才进内帘。他将自己在栈城用过的问纸压在发页案上，请这人顺路递过去。读表人拿起看了一眼，把它还给白礁。过去老师领样由教用夹找，这一回带了两个来问的人，该到那头正门交，由里面给三人各记一笔。

他们从案后绕到内帘之前，沿石板走过半段架高的木廊。栏杆底下整捆空白纸用布围着，漏光的地方能看出纸边微微卷。有人提着灰斗从港里更高一段走下来，倒过一道扫出的木糠。细屑从廊板间落下，白礁抬包躲开，让林渡留在他脚后一步。右侧有几块板越走越窄，一只手若扶住纸夹，另一只手得去找栏杆。林渡把自己的副联推回胸前的内袋，空出左手抓住柱子。弥娅在窄过道前等他走完，将曲荻的请认联和自己写的来意一前一后排好，递给帘边看守。白礁从自己包中另取问旧柜的那份。

出来的是管旧架的女人，袖口扎有两圈不沾纸边的短布。她请弥娅先把白礁的原领用签号报一遍，又让白礁自己报当时领取的是哪几页。旧表的整册当年也没出港。白礁当过带读人，可以取原架的一个局部样去教。她听到“第一放绳岸端”，去窗下取出一本薄一些的登记本，让白礁从当年一排过去看小栏。白礁眼睛跟着她的指头走，到末尾还往下挪了一行，忽然说这一手同自己记得的印不一样。

她合上薄本，问三人打算带哪些抄件走。弥娅说要当原架核页号、抄次与收阅签，两岸都缺的栏要照原样留着。管柜人便从门边抽了一只硬封套。她说若想连着看一个整凉，林渡带来的衡陆副联和白礁手里的教学样得先交进同一个封套。旧架原页还归原柜。馆里照收下的两张和原页抄成一份合本，三人看完就走，等馆里的人核好了再领合本。要领回自己带来的那两张，也得由馆里的人开封。

林渡把自己的副联取出来，问她可否现在当面给她认段号。女人伸手向案内比一比，封套的两角已经折好，空的那处足够放白礁的教学样和林渡带的副联。她说眼下这样看看，自己的印不会落到他们两岸的纸上。如果留下一处保管，里外经手由她记，可以给留一个靠窗的位置，从这凉开始，一直坐到铃响收桌。林渡的副联就在手边，手松一些，这一趟的纸和澜陆的原页就能在同一张桌上摊很久。从在栈城上船那天算，到这张案前已是第六天。第二岸船还得在外头重新等适合离港的水面。三层交口还留着同字的一份。林渡捏着手头这张的封角，往掌里按紧一寸。

“我把这行给你认。”他将副联翻到获准出查的那一面，“认完我收。查到什么，各带自己的回去。”

管柜人拿起空套，轻敲一下桌边。白礁的手搭在样张夹上。他看弥娅，她站在两人之间，手里那张曲荻的请认联没往封口递。管柜人等了一会儿，将封套夹进自己腋下，说按普通来阅的办。普通阅位只剩明日的前半凉，在内帘边开架，三人各挂一个临阅牌，有什么话在那里说。抄件须当面签明范围，谁抄谁收。她伸手示意这凉的长阅位仍空着，等他现在给一句准话。

管柜人朝背后比给他们看。隔开旧架的那一格桌，近处沾的是从门缝吹进来的矿物细灰，远一点有两道常年靠纸磨出来的白痕。一个来候阅的人抱着夹子贴墙等着，脚边有一条缝不断漏进热风，他每隔一会儿就换一次脚。三人占了明日的前半凉，后面的人也有自己的半凉。谁愿意把纸留下，才会有人关帘以后代着查。林渡听清这两个办法，手上的副联靠近自己胸前，等着新牌上那一笔写完。

弥娅照原话译到“前半凉”时顿了顿，用指头在自己衣边写出半道横。林渡叫她把两岸的号各念一遍给管柜人听。他把五层准出的那一面在两人眼前摊开，给看旧档的人指出两格中间多一手的位置。管柜人听弥娅念完，用新纸写号，不复摹签背的印。白礁随后也在写好的号旁认了教学样来自哪一格，纸仍合在自己手里。管柜人把三个人请认的内容分别读了一回，才伸手去拿暂阅条。

白礁看她把“旧架收”和“教用领”两份签从不同夹里夹出来，抢前半步。两张上端都是方才查过的旧表号，边上都有一道细斜线。方才她让他只看薄本，里面写了教用领之后样页发出去供课。他自己以前见过的一处收栏在背面，要翻起来才见。两纸并排，管柜人推开靠手背那张的下面一点，露出早先被纸条压着的去处。教用领上写样页退旧架，另一张的去处却写着“送阅订本”。送了几页、谁收到，那两个格子在这张签上找不到。林渡没听过“阅订本”这个旧称，请白礁按他记得的写在木板上。白礁写前一字的时候笔尖顿了一下，往后两字再不须弥娅帮他指。他说自己当年只认归旧架的这一手，有人嫌课上少放一张便会从那边叫他回去。他把笔递回去，木板上两条各去一处的路已经分开。白礁隔着台角伸起一根手指，没有碰到纸。他请弥娅把那三个字原样记，别按现在的话翻成给学生用。

管柜人将两张签夹了回去，只让他们看到这一面的号和去向。她说要找旧架本页，明早得等钥匙从收柜人那里交过来，再到原格上照签。等钥匙转手以后，往哪儿送阅订本还可能要问另一头。她把临阅的时段在纸上写清，沿帘边挂出三块小木牌。林渡收好自己的副联，临走前问弥娅，发同号的两手明日能不能跟旧表同放一处。他们得沿石廊回候棚，另向守棚人议定再借一夜。弥娅翻过刚写过的纸，说自己只听见开旧架的格，她会带这两条去问，先请白礁亲眼认一认，另签沿用这本旧表的号，送阅的究竟是不是他教过的那一页。
