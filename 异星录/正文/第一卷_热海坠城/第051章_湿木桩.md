# 第五十一章 湿木桩

外壁第一根木桩湿得发亮。

林渡踏出孔位，先把腰绳留在身后的旧梁上，没有抓桩。铁皮包着桩腰，水珠从上面的冷石壁滴下来，沿接缝渗入木纹。水在锈边积成一线，落进木纹时带出淡褐色木汁，桩脚那一圈已经胀得比上端粗。他用残裂木尺敲了三下。前两下闷，第三下之后，里面传来细碎的塌陷声。

“不能挂人。”

阿九蹲在靠山一侧，用扳手柄压第二根桩。桩身略微弯曲，连着外层木板的铁环便向外歪。他立即卸力，左膝却没能跟着直起，只好撑住石壁慢慢挪回来。

桩外是黑汽，桩内是一条残留的铺板。板下横撑插入山壁，勉强留得住人的脚，却不能再把所有人的重量挂到桩上。刚从官方入口绕出的居民挤在后方窄平台，前一副担架已经停在第二孔附近，后面的尚未离地。林渡让抬担架的人先蹲下，把重量落回横撑，不要悬在绳上等。

“前面的别回头。后面的退到板缝里面。”

杜姨从后面逐句传话。人群终于松开一线，林栖抱着手摇冷凝灯贴到墙边，腾出了送绳的位置。

那六个旧孔都还在。第四孔的空响，林渡刚才听过，不能因为木桩更坏就重新算作好孔。上方灯号三闪一停，小石沿着灯光指了指第三孔下缘。后来钉上的铁皮遮住了孔口，下面露着一截旧环。

林渡伸尺探过，尺尖擦到的不是孔底，而是一层松灰。他收起裂尺，让阿九拆开护片。旧环从石缝里伸出，根部连着深处的横铁；旁边木楔虽已泡软，横铁却没有随扳手一起晃。

“先走空绳。”林渡说。

阿九把绳尾穿过去，来回拖动。毛刺刮起了一点绳毛，麦穗立即叫停，将拆下铜管的光滑弯面垫在转角。那是房车冷却器最后留下的东西，如今只能护住绳皮，不能再给任何人降温。

零件箱被送上去时，林渡盯着环根。箱底擦过铺板，绳子只是防它滑下去，没有把整箱吊空。铁环不动，孔边的灰也没再掉。

“箱子比人轻。”岑野说。

“所以还没试完。”

林渡保留身后旧梁上的保险，把前绳接到腰间，双脚仍踩横撑。他一点点后坐，等绳绷紧，再挪开一只脚。阿九压着孔边，麦穗看绳结有没有滑进铜管缝。直到林渡把重量重新还给脚下，三人才各自点头。

这样只能确认眼前这一段，不能替上面的孔担保。

林渡把主绳留给担架，另一股贴墙走，供人扶握和挂腰套。两股绳仍不许同时加人：前一副担架落稳，后一个才可跨出。踩的是横撑，不是绳结，更不是湿木桩。

岑野先空手过去。他到另一端后伏低身体，把担架头上的牵引绳收紧；麦穗留在这边守尾。杜姨检查伤员胸前和髋部的布带，确认不会在倾斜时滑出，再让两端一起抬。

担架越过板缝，铺板先发出一声细响，海侧那角才向下坠了半寸。弥娅没有抬手，先把手掌按在仪器布套上，等水珠改向才开口。

“停在撑上，别跳！”林渡喊。

弥娅贴墙站在前端。她的测潮仪仍在胸前布套里，屏上的箭头早已散了，不能为一块木板的回弹报时。她看见缝中水珠被风推向一边，便指向脚下。

“先别送。下面在出热气。”

林渡沿墙下蹲，直到铺板的挪动停止，才让岑野继续收绳。弥娅负责看热流，他负责看脚下，这一次没有谁能替另一个答应安全。

轮到裴七扶担架尾时，他的左腿蹭过翘起的铁皮。布裤立刻开了一道口子。他没叫，脚却往回缩了一下，担架随之歪斜。

杜姨把他拦到横撑内侧，先让别人接手。她取盐药时，一滴积在护板后的污水正落到开口上，纸封塌了，里面原本干燥的药粉结成灰团。她看了看，没有往伤口上放。

她把纸封翻过来，见底面也吸了水，才说：“这一包不能清创了。”

裴七盯着药包，抓在横杆上的指节慢慢收紧。杜姨把它与剩余药分开，取干布压住裂口；早先受潮、只用来隔布的材料也另放一处，不与干药混装。

林栖将药袋抱高，换到灯照得到、不会滴水的墙侧。搬运时它和伤员一起过绳，不再搁在潮湿铺板上等最后一趟。杜姨把坏药包另收好，仍让林渡把这一笔写下。

水票册从她手中交回时，封皮已经发软。林渡靠石壁写完裴七的名字，暂记左腿裂伤、需再处理，随后收进衣内。

“我还能搬。”裴七先把横杆上的泥抹掉，才抬头。

“你只扶尾，不抬。腿疼就报。”

裴七把肩上的备用扣带交给林栖，自己试着屈膝。伤口一扯，他停了片刻，才扶着横杆站回队尾。少了一个完整的搬运人，之后每副担架都得多换一次手。

阿九清理第二处护板时，扳手碰出金属脆响。板后钉着一块发黑铜牌。林栖用布擦掉表面泥垢，辨出“公共工程署”，背面还有一句被磨去半边的字。

“先保结构，再保通行。”她慢慢念。

林渡抬头看了看上方的灯，又看向脚下后加的木桩。旧孔和新桩不是一套承重，牌子也不能替年久失修的横铁作保。他让林栖把牌收进灯袋，另画下可用孔位，空响的第四孔旁留一道叉。

她右掌伤口不敢压笔，便把册页夹在左肘与墙之间，写得很慢。麦穗替她摇灯，蓝白光稳住后，她才看清那道叉没有落错地方。

一个孩子在第一处断板前不肯动。鞋底刚被铁皮割穿，杜姨用布带束住鞋面，没再让他踩那个边。林渡把孩子的腰套接到扶绳上，先指自己鞋尖所在的横撑，又指向下一处。

“脚落这里。手松开换位置时，腰上的绳也不解。”

“会掉吗？”

“我在后面看你的脚。前面有人接。”

他没有说绝不会。孩子伸腿试了一次，没够着，林渡就叫前方把牵引绳放松一点，让他能蹲低，而不是拽着腰把他吊过去。岑野伸手接稳孩子，才喊后面可以动。

每挪过一个孔，人都要停下喘气。从外壁起步时留下的那点可行余地在这样消磨，海侧的水汽渐渐变暗。有人要把药袋递给孩子代带，杜姨拒绝了：孩子的两只手都要留给攀行。

弥娅将一条已有的湿布贴近前方缝口，不碰伤腿。布角先往外飘，随后被向上的热风托起。她提醒众人绕开缝口，自己扶墙侧移，左小腿不能跨大步，便把一个落脚点拆成两次换脚。

林渡等她站定，才把下一副担架送出。谁慢下来，后面都得跟着慢；硬催只会让同一段横撑同时多出几个人。

林渡让人把长梁贴墙立放，梁尾抵在内侧横撑，别横在过人的路上。阿九想将零件箱留在下面，减轻下一趟负担，摸到箱角又停住。往后若还要开孔、接绳，他们连取零件的地方也没有了。

“箱子走，人晚一点。”他把箱带扣到绳上，“不是为了我的破烂，是上面还没一条能走的路。”

箱子到达后，麦穗先接住箱带，再解牵引。她把空绳放回，岑野却伸手拦了一下：刚才绕铁环的那一截已经起毛。阿九不能隔着人伸手修，便让她用指肚摸清破皮处，将它移出转角，不许再卡在最吃力的位置。

林渡没有催。他左肩从旧伤里一阵阵发热，抬手收绳时肘部发抖，只能把绳绕过完好的横撑，用身体后坐来收短。后方的人看见他也得借木头的力，终于不再只盯着他的手，开始互相提醒腰套和脚下的位置。

最后一副担架的前端靠上第二处横撑时，后方平台传来一声低沉断响。裴七还在旧板上扶尾，林渡转身去接他的手，脚底却先向海侧滑了半步。

湿木桩一根接一根下沉。林渡先听见绳纤维被拉直时的细响，掌心随即被绳皮勒出一道白痕；担架尾部被那一下压得向外偏。
