# 第五百零一章 船还在往里走

栈城货场才把第一笼空瓶抬上架，背水阶的岸工就赶来叫人。他的裤脚一边干着，一边湿到了膝上。

“送药的短渡艇回来了。船上的人往外打手势，船还在往里走。”

林渡从靠墙的条凳上起来，右臂的吊带被凳角勾住，勒得他颈上一疼。他用左手拨开带子，问船在哪里，船上的人有几个。岸工伸指按住货场下面那条过缝的人路，说两个人，载着从邻湾空手回来的药篓，艇已经进了夹水口。原先那条在岩外等着补舷的第二船还好好泊着。今早多了一条挂长旗的大船，守住夹水口外侧，两根带浮子的标绳从船上放出来。短渡艇没过去，回头被推到背水阶斜外面。

曲荻本来坐在条凳另一头，手边是刚换过护布的封件。她把封件提起来让林渡看自己的两只手已经空不出来。

“药篓为什么是空的？”

岸工是从石阶上看见篓底的。他没问着人。短渡艇原本应沿同陆岸线去邻湾探一处药，今晨出发时，夹水口连条看鱼的人船都没有。

“小石，请交口值岗借两个人。”林渡说，“要走过这两道缝的。再去找绳，车上的别拿。”

小石原在另一架空瓶旁理递条，头一个字没听清。他往回走了两步，把哪两个活复述一遍，沿货场干侧跑出去。林渡听到他的木底鞋在坡口一滑，接着又响起来。曲荻退到台里的干面等本地值岗回来，封件仍由她守。

林渡和报信岸工沿两道窄缝下去。第一道能侧身并行，第二道往外下的人得等前面的脚着了实处才跟。前一夜海风把水滴送进缝里，岩壁朝海的一面手一抹就沾湿。林渡过去常用右臂撑住这块岩，现在只能让左鞋贴着山侧的石筋，一步步挪。下了缝有通往岸台的平处，风从那里顺着人脸刮过来。阿九正坐在原车门边，守锚的人也在。林渡把打算先救艇人的话交给他们，请阿九在岸台替他看外水的来势。若岸阶下的人听不见退令，阿九坐的地方可以朝缝口再喊一遍。

“我这条腿今早只许做一件事。”阿九把左膝往门板里收，“抬它还是抬嗓子，先说定。”

“嗓子。”

背水石阶只露到中阶。岸工在干石面朝艇尾挥手，林渡顺着他举手的方向看见一片泡水发深的木舷。短渡艇上的一人跪在前头，另一人从艇尾往岩面推桨。他每向外推一次，艇身就在回水里横一次。篓倒在两个人中间，系篓的绳却绷直了，一头没进艇的外边。林渡沿它入水的方向看，浅处有一截旧系柱从侧岩下伸出来，柱梢离水面只剩几指。一股水在柱后回卷，拉住篓绳不肯松。艇尾把桨收回时，艇前脚下那段舷正往柱梢撞。

夹水口之外的长旗被风抖开。林渡站在岸上只辨出深底和浅边。那条船离得远，有条小艇贴在它近旁，标绳上的浮子排成弧，拦的是出夹水口往外的那股水。岸工张嘴想喊那边的人放行，林渡指着回水，叫他朝艇前的人喊。

“篓绳拿得着吗？”

艇上的人只听清了最后几个字。他往篓跟前伸手，艇尾又斜进去一截。林渡把岸工叫回干石，趁水声低下来往下喊：“趴低！解你膝旁边那一头！”

艇前的人用腕子压住篓沿，挨到下一次船身扬起来，猛地把手缩回了胸前。篓边一道尖木条擦破了他的指节，血贴在皮肤上，被热风吹得很快发黏。林渡看到他把伤手举起来，一只手却还攥着篓绳。篓柄缠着一条洗得发白的护手布。艇身一摇，那人把它往膝下拢，篓口刚贴住腿，船又向旧柱偏过去。

小石带着一位卸货工和一位补壶摊的邻人从岸台赶下来。工人肩上盘了一根用过的公用索，是交口值岗从货架边实取的。他向林渡亮出索的一端，麻股里没有从水里捞起来的泥，末端的旧缝补只够绕在干处，不能落到柱梢上磨。林渡叫他站到干阶后方，把索绕过石肩内侧那处完整的凸角。补壶摊的邻人身量轻，自己蹲上中阶，等艇尾第二次荡向能摸着的位置，将索头放进后面那人的怀里。

“等他割绳再牵。”林渡叫道。

水从艇侧拍起来，几点落在邻人裤腿外面。他退高一级，先扯开贴住肉的湿布，绳头那边还掌在艇尾人手里。前面那人把贴在篓底的小刀摸出来，刀口已经蹭过两回，绳仍连着。他把伤手连篓沿一起压住，低头割第三回。绳一断，舷侧在旧柱梢上响了一下，留下一个新磕痕，艇却继续跟着公用索往上游那面挪。林渡留神看掌索人脚下。起头要硬拖，鞋会跟着往石沿滑。他叫等了两个涌头之间那一点空，再让两人同时往回拿索。

阿九在上面喊了一声。林渡先看见一片水被风压向石阶，才听见那个“退”字。艇尾人已经站起来，林渡让他重新坐下。水从艇底过去，打在刚才补壶摊邻人蹲的位置。邻人的裤脚有一小片还泛着光。补壶摊的邻人扯起黏在小腿上的裤脚。风一吹，他烫红的小腿缩了缩。他提着裤脚，自己沿干阶走上去。艇里面两个人把头压在舷内，等压在石下的水声退远。下一次艇身回到石肩跟前，艇尾人将桨横在自己膝上，扶艇前的伙伴先跨阶。岸工双手托住那人的胳膊上端，避开伤手。剩下那人跳下来时自己带了缆，把空艇系到同一侧的稳石，公用索松回卸货工手里。

热时将起，夹水口能走的小段水先收窄。林渡看着漂离艇边的断绳浮过第一级下面。他原来想着，若趁今日去认一次返航的熟水，还能带一眼看得见的外海消息回来。卸货工问要不要等下一股退水，把短渡艇借来往旗边划。他抬起左掌，指尖早在下缝时麻得不大听使唤，掌根才被索身扫过，原来一道干裂也出了血。

“先收索。今凉不上水。”

补壶摊的邻人能自己走，但小石把他的裤脚往上卷了卷，让他到岸棚给当班医者看一眼。林渡同他们走上岸台，留岸工照看空艇和两名从水上下来的人。岸棚檐主已经在低台旁等，昨日便说定今凉来查积水槽。姨母把孩子原来的瓶挪到托面近手一侧，脚踝还垫得高。檐主弯腰拿走槽下自己昨天铺的一块薄木，木背没有新水痕。他只肯把原檐续到再过两旬的那一天，届时实看檐和引水槽。要加挂风布，他得再来看看落力的木头。姨母把日期念给孩子听。孩子正掰手指算，听见进棚邻人的步声，先把脚边搁着的空凳推给了他。

医者手边那一小格药刚分过，一包的内纸已折得很小。他请邻人坐着，让帮手用医疗罐里另留的水缓一缓烫到的地方。艇前那人上来后自己举着伤手等。原先走短渡探药的两个人中，他的手快，两边都请他做跑船的活。他一坐稳便去摸腰侧平时挂篓的带，手指够到空的扣，停了停。

“邻湾的船也被叫回去。”他说，“那边有人往我们这儿做手势。两个胳膊交在一起。我以为他们要我们快些回来，没问清是今天这一条艇，还是以后都不给过。”

林渡请小石把听见的话带回交口，别把邻湾人没有说过的日期添上。随后他沿岸台绕到能看见外侧的一块岩石上。长旗底下的小艇离开了巡船，桨手只把艇送到浮子内侧，朝岸上高举一张绷在木板上的白纸。举纸的人喊了一遍，被夹水口冲上来的浪声截去一半。林渡招呼岸工一同回背水阶的干面。

下一次退水前，至少得有人下到那人听得见的地方，把整句话带回来。
