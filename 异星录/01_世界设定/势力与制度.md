# 势力与制度

## 1. 上城区议会

上城区议会是栈城内部的统治机构，不代表衡陆全部地区的统一政府。它依靠栈城的水库、身份系统、广播和通行设施维持城市内部的上下分层；衡陆其他城市与聚落的制度不在本表默认范围内。

| 项目 | 设定 |
|---|---|
| 公共说法 | 维持栈城秩序、控制水源、保护居民 |
| 实际目标 | 控制冷却水和潮汐武器，把灾变成本转给下城区 |
| 核心资源 | 水库、身份印记、广播系统、护卫、撤离船 |
| 内部派别 | 赫连的效率派；保家派；知道真相但沉默的档案派 |
| 公开底线 | 不允许下城区大规模进入上城区 |
| 内部矛盾 | 议员家属已撤离，普通上城区居民却仍被留下 |
| 第一卷行动 | 虚假播报、转移冷却水、封锁断阶、删除下城区名单 |

赫连必须曾经做出真实治理成果：他在过去十年让上城区死亡率最低、冷凝站运行最稳定。因此普通居民对他的支持不能全靠恐惧。问题不在于他不懂管理，而在于他把“少数人的稳定”当成唯一正当性。

## 2. 下城区互助会

| 项目 | 设定 |
|---|---|
| 公共说法 | 负责分水、修木架、救伤员 |
| 实际诉求 | 让下城区拥有自治权和公开配给账 |
| 核心资源 | 水票册、工匠、街区信使、旧木材仓 |
| 内部派别 | 先救人派；先夺水库派；只想护住本街区派 |
| 公开底线 | 不能把居民姓名从水票册和葬礼记录中抹掉 |
| 第一卷行动 | 组织分水、抢修木闸、护送居民、把水票册交给林渡 |

互助会不是天然正确。它也会因为资源不足隐瞒伤员数量、排斥陌生人，甚至考虑把弥娅交出去换冷却水。林渡的成长包括让互助会从熟人互助转成能容纳陌生人的公共组织。

## 3. 无面者

| 项目 | 设定 |
|---|---|
| 公共传言 | 住在断阶黑暗中的杀人者和掠夺者 |
| 实际目标 | 守住旧维修室、档案和隧道入口，防止议会彻底销毁历史 |
| 核心资源 | 断阶路线、维修工具、旧爆破记录、面具身份制 |
| 内部派别 | 槐七的谨慎派；主张暴力封门派；愿意公开档案的年轻派 |
| 公开底线 | 不让议会拿走潮汐晶片 |
| 内部矛盾 | 守密方式已经伤害下城区普通人 |
| 第一卷行动 | 观察、试探、夺取木尺、保护旧维修室、与难民临时架桥 |

无面者的面具不是超自然象征，而是防止议会通过身份系统追查家属。摘下面具意味着愿意以真实姓名承担公开证词和法律后果。

## 4. 远潮商团

| 项目 | 设定 |
|---|---|
| 公共说法 | 运输海盐、零件、药品和冷却设备 |
| 实际目标 | 垄断跨海贸易，向双方出售稀缺物资和情报 |
| 核心资源 | 船队、仓库、价格账、两陆黑市关系 |
| 内部派别 | 逐利派；希望开放海峡的航运派；与议会合作的安全派 |
| 第一卷表现 | 通过价格和仓储影响水票、盐药和旧零件流向 |

远潮商团不是最终反派，但会在每次秩序崩溃时获利。第五卷以后，部分商团成员会成为共同工程的物流骨干，说明旧组织也能被改造。

## 5. 潮庭

| 项目 | 设定 |
|---|---|
| 公共说法 | 澜陆的学术、政治和潮汐技术中心 |
| 实际目标 | 取得冷却技术和潮汐数据，维持澜陆资源优势 |
| 核心资源 | 测潮学者、勘探舰队、潮相档案、港口军力 |
| 内部派别 | 学术开放派；资源民族主义派；与旧贵族合作派 |
| 第一卷状态 | 只通过弥娅的记忆和测潮仪间接出现 |
| 长线矛盾 | 他们指责衡陆删史，却同样删改了本方战争记录 |

### 对弥娅的政治处置时序（C01已确认）

251—350只能写合作条件收紧、资料独占要求与失信，不能写潮庭已正式判她为叛徒；400正式回应前不为此补造政令传递渠道。401后须区分使团派系的威胁与机构正式处置。476弥娅公开本方删史，随后拒绝撤证和交出独占数据，500由潮庭首次正式宣布叛徒并撤销官方保护，构成六卷封锁的政治原因之一。

通告的发布者、来源、送达对象和执行范围须有现场证据；一个港口收到不等于全澜陆同步执行。定罪理由属于潮庭政治立场，不代表作者认同。详见[后七卷设定决策与执行约束](../00_项目总览/后七卷设定决策与执行约束.md)。

## 6. 黑潮教团

| 项目 | 设定 |
|---|---|
| 公共说法 | 热海是神罚，异星人是灾厄源头 |
| 实际目标 | 以恐惧获得水、信徒和撤离名额 |
| 核心资源 | 传单、葬礼、避难棚、街区传教者 |
| 内部派别 | 真诚信徒；鸦母的清洗派；暗中抢名额的高层 |
| 第一卷行动 | 散播异星传言，袭击冷凝站，使用来源不明的上城区武器 |

普通信徒不等于高层。写教团场景时必须同时写出灾民恐惧和权力利用，不能用一个祭司代表所有信徒。

## 7. 身份制度

### 身份等级

| 等级 | 允许使用 | 被拒绝的内容 |
|---|---|---|
| A级 | 七层住房、水库、撤离设施 | 无 |
| B级 | 五至六层住房（六层住房限核心外缘工班家属，凭身份额度持门禁）、正常配给 | 武器站、档案深层 |
| C级 | 工坊、冷凝站、有限水票 | 上城区居住、档案馆 |
| D级 | 下城区基础配给 | 升降机、上城区入口 |
| 无印 | 无固定配给 | 所有身份门和官方名单 |

### 制度如何制造冲突

- 身份印记失效时，门不会解释原因，只会亮红灯并重复“权限不足”。
- 议会可以把一个人标记为“已撤离”或“已死亡”，从系统中删除其水票、住房和证词。
- 祝衡的转变不是从有秩序变成无秩序，而是从服从权限转为要求权限可被公众审计。
