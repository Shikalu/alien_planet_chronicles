## 2. 第一卷关键地点表

| 地点 | 相对位置 | 视觉记忆 | 剧情功能 |
|---|---|---|---|
| 林渡住处 | 1层一环内侧 | 低矮船板屋、梁柱编号 | 主角生活起点、木尺来源 |
| 第一冷凝站 | 1层一环外侧、通往二环的斜桥旁 | 蒸汽、滤芯、蓝白冷凝灯 | 林栖被困、解释水资源 |
| 交换市 | 2层中段 | 水票、盐药、拆船木摊 | 经济与群众冲突 |
| 互助会 | 2层靠山 | 公共水票册、木楔墙 | 群体组织和首领牺牲 |
| 阿九房车点 | 2层外缘 | 破旧小房车、零件挂绳 | 喜剧缓冲、列车船核心 |
| 货运坡道 | 3层北侧 | 废轨、蒸汽盲区 | 连接路边小山和隧道 |
| 路边小山 | 3层外侧 | 被热雨冲刷的黄土和灌木 | 房车撞入、发现旧轨道 |
| 断阶下缘 | 4层南侧 | 悬空木梯、黑色水汽 | 第一次进入断阶 |
| 断口 | 4层中段 | 断裂横截面、炸药孔 | 人为爆破证据、跳跃 |
| 旧维修室 | 4层深段 | 低温、工具墙、来源未明的两端接口徽记（作者底稿为两陆共同徽记，正文第88章不命名） | 林岑、潮汐晶片和证词 |
| 无门街道 | 5层外缘 | 整齐街灯、无可见入口 | 上城区权限制度的实体化 |
| 秘密撤离船 | 7层观测台 | 白色船身、海峡武器站徽记 | 第一卷终极钩子 |

## 3. 第一卷路线顺序

```text
林渡住处
  -> 第一冷凝站
  -> 一环坍塌带
  -> 二层交换市 / 互助会
  -> 三层货运坡道
  -> 路边小山（第一卷只发现，不打开隧道）
  -> 断阶下缘
  -> 断口
  -> 旧维修室
  -> 断阶上端
  -> 五层无门街道
  -> 七层撤离船视线
```

## 4. 移动成本

| 路段 | 正常时间 | 坍塌状态 | 必需条件 |
|---|---|---|---|
| 住处—冷凝站 | 半个凉时 | 一个凉时 | 水袋、短钩 |
| 一环—二层交换市 | 半个凉时 | 一个凉时 | 可走木桥或房车 |
| 二层—三层货运坡道 | 一个凉时 | 两个凉时 | 车辆或绳梯 |
| 货运坡道—断阶下缘 | 一个凉时 | 两个凉时 | 绳索、避开蒸汽盲区 |
| 断阶下缘—旧维修室 | 一个凉时 | 两个凉时 | 无面者路线或旧标记 |
| 旧维修室—无门街道 | 一个凉时 | 三个凉时 | 临时桥、风向读数 |

移动不是填空过程：每跨一段至少消耗水、能源、绳索、时间或队伍完整性中的一项。
